## 重大重構里程碑

### 2026-05-18 ─ 武器分支簡化 + 工作流程四階段釐清

> 決策檔：[D-20260518-01](../decisions/D-20260518-01-武器欄位簡化.md)

| 變動 | 細節 |
|---|---|
| 主從合一 | `slaveMesh` / `scope` 廢除 → 改 `main_mesh_node` 單一欄位 |
| 武器 magnet 強度動態 | 廢除 `magnet_strength_n`（武器靜態值）→ 改 `applied_energy × K_MAGNET_FORCE` 動態 |
| Launch 簡化 | `LaunchPoint` empty 廢除 → 子彈 = `main_mesh_node` 子節點 mesh |
| `on_impact` 廢除 | launch 落地行為由 bullet 材質決定，不需要欄位宣告 |
| Mount 軸檢核精簡 | 僅 tire / roller 兩類做軸向檢核 |
| 裝飾 mesh 材質 optional | 純裝飾（`physics: visual_only`）可不指派材質 |
| 工作流程四階段釐清 | 上傳 → 編輯（wave A+B）→ 上鏈 → 組裝（Loadout） |
| `n_pole_direction` 欄位廢除 | 場地磁場 N 極改為 mesh-local +Z 軸自動推導 |
