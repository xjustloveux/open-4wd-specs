## 重大重構里程碑

### 2026-07-02 ─ 檢舉/仲裁/DMCA 大改：類型 4 種、仲裁 7/4、DMCA 維運層化、聊天簽章、個人封鎖清單（跨 ~20 檔）

> 決策檔：[D-20260702-01](../decisions/D-20260702-01-檢舉仲裁體系大改.md)、[D-20260702-02](../decisions/D-20260702-02-DMCA維運層化.md)

信譽系統複審收尾（#4 騷擾/作弊 reason、#5 豁免接線）滾成整包重構，逐項與使用者細部討論後裁定執行。

**檢舉類型 7→4**（`ReportReason`）：`copyright-violation`（**剽竊併入違反版權** −100——受害者身分差異非罪名種類；原 `piracy-arbitration-loss` −50 廢除）/ `griefing`（**騷擾限縮到對話** −20，新 reason——「比賽中故意干擾」刪除:武器攻擊是合法玩法、惡意與競技無法仲裁區分）/ `inappropriate-content`（內容不當 −20 = `ugc-blacklisted`）/ `other`（−20，**借對象所屬桶標籤**:對 UGC→`ugc-blacklisted`、對玩家→`griefing`；原「依仲裁判定」不可 derive 廢除）。**廢 `plagiarism` / `physics-cheat` / `low-quality`**（品質歸 rating/退役非違規）。**作弊不是檢舉類型**:改物理/偽輸入/假結算由自動機制攔（desync/簽章/多簽/PeerScore）,能過確定性驗證的仲裁也無從舉證（外掛代打 = 架構層無解）；原「作弊→直接黑名單」特例消失。`ReputationReason` 維持 10 種（−piracy +griefing）。**上傳期灰區仲裁（70–90%）= 只拒收不扣信譽**（未上鏈無實害、可能撞衫），與事後定罪 −100 分開。

**仲裁參數定案**（原「N 待治理校準 5–7」）：`ARBITRATION_PANEL_SIZE = 7`（quorum 4 下 7 人只需 ~57% 回覆率、6 人要 67%;流局重抽燒整個新面板,+1 席買保險期望值更省;合格門檻使 weight ∈[2.32,3.00] 差 ≤1.29× 近似人頭）/ `ARBITRATION_QUORUM_VOTES = 4`（**有效票** pass+reject,棄權不計——防 3 棄權 1 pass 一人定生死）/ 重抽上限 1 次（新檢查點 seed + 排除缺席者）,仍不足 → **流局**（非 reject、不進準確率、可再告）/ 池 <7 流局 / **撤回窗 = 抽籤前**（抽籤點 = 檢舉後首個滿 24h 檢查點 `ARBITRATION_DRAW_DELAY_HOURS`;防看風向撤回重骰仲裁者;原「主動撤回永不可再告」廢除,撤回/流局/過期均無懲罰）/ 過期「判 reject」改流局。仲裁激勵 = 開放項（playtest 看回覆率,若加 = 有效票 +1 信譽、client 發版非治理）。常數進 程式參數表 §5。

**玩家全域黑名單 = 純 derive 三振**（`GLOBAL_PEER_BLACKLIST_STRIKES = 3`）：同一責任人（被檢舉玩家本人或被定罪 UGC 作者）仲裁定罪 ≥3 → 全網黑名單。**廢 `ModerationActionEvent`**（「誰簽這筆事件」從未有解、「多次違規累積達閾值」閾值從未定義,derive 全消掉）；凌駕 moderation.md §7 舊軟立場（多作品只靠 -20/件累積壓力）。**用語分流鐵則**:全域「黑名單 blacklist」（帳本推導）vs 個人「封鎖清單 blocklist」（本地）,spec/UI 不得混用。

**DMCA 維運層化（零信譽足跡、不上鏈）**：原鏈上 `DMCA Agent multisig`（維護者+社群代表+法律顧問、floor(2N/3)+1）**整組廢除**——出 client 版的人本來就有終極權力,鏈上多簽是治理劇場;匿名 PeerId 無法承擔法律身分。改**維運層模型**（使用者提案）:①**兩層下架** = 即時層 pinning/索引（法遵「迅速移除」在此滿足）+ 發版層 **client 下架清單**（repo `dmca/takedown-list.json`、PR review、隨 minor 版出貨、無配對閘、同材質絕版品模型、可逆——誤判清單移除+推版+立即 re-pin）;②**信譽 −100 只留檢舉路線**（`ArbitrationResultEvent`;硬技術理由:信譽是帳本 derive,吃隨版本清單會跨 peer derive 分叉;原 DMCA 路線 −100 + Repeat Infringer「2次−100」廢除）;③ **Repeat Infringer ≥3 = pinning/索引層拒服務**（safe harbor §512(i) 法遵要件,不動 client/鏈/信譽;`REPEAT_INFRINGER_THRESHOLD` 退出 EconomyConfig 治理面 → pinning 維運政策常數）;④ 法律顧問全程離鏈（原「證明文件上鏈公開」評估為不合理+法律風險:append-only vs 個資刪除權）;⑤ 社群代表選舉（EndorsementEvent + 活躍者支持度）連帶撤案;⑥ 透明度報告 = 純 derive（後端 dmca-notices publicView + 清單 git 歷史,不另簽季報;原「DMCA Agent 簽署寫 ledger」廢除）。DMCA 首犯 = 警告+下架（原主流程首犯 −100 與 Repeat 表矛盾,取表）。

**聊天訊息簽章**（修 drift——資安規範 §3.2「所有 P2P 訊息簽章」本就無聊天豁免）：`ChatMessage` 走 `SignedPayload<T>` + 新增 `roomId`（簽章涵蓋、防拼接挪用）;**簽章聊天 = 騷擾檢舉可驗證據**（PeerId 即公鑰、仲裁者離線驗真,`exportEvidence` API）;**收訊端 per-sender 5 則/秒強制丟棄**（原只有送端自律,惡意 client 可跳過）+ sender=signer + roomId 三檢。

**個人封鎖清單（blocklist）新功能**（使用者提案）：純本地、永不上鏈（上鏈=公開羞辱名單+報復導火線）;配對/瀏覽過濾含封鎖對象的房、我當房主拒加入（通用原因不揭露）、封鎖者中途進房=提示+一鍵離開（不自動退、房主權威）、兼聊天靜音、觀戰不擋。canon 賽內機制 §1.7、impl matchmaking.md §3.1。

**anti-piracy 平行仲裁系統收斂**（順帶撈出的舊 drift）：原 challenger/defendant 決鬥 + **全社群 7 天投票** + 孤值「信譽 -10」+「發起扣信譽、落敗加倍扣」+ `ArbitrationApi`/`UploadDispute` 整組廢除——開放投票正是純仲裁裁定要排除的串謀形狀。收斂進標準檢舉仲裁（上傳期案無檢舉者無 reporter delta;事後案 = 違反版權檢舉,不成立 = 共存;濫訴反制 = malicious-reporter 三條件）;上傳灰區 'proceed' 選項移除（衍生流程 §140 blocking 為準）。

**#5 新手仲裁豁免 = 不豁免（廢除）**（使用者裁定）：刪 信譽系統 §4.1「比賽 <10 仲裁不扣」列 + reputation.md `shouldApplyArbitrationPenalty`——仲裁本身即防線（隨機面板加權 >60% 才成立）,豁免反是小號護盾。新手保護剩 7 天下限 400 + UGC <3 檢舉門檻提高。
