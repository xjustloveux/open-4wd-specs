## 重大重構里程碑

### 2026-07-29 ─ 文檔工程：跨 repo 規則追溯改採 ownership 模型

> 決策檔：[D-20260729-01](../decisions/D-20260729-01-跨repo規則追溯ownership.md)

- 規則 registry 新增 `implementationRepos`，Specs 以 `rule-ownership.json` 維護預設 main ownership 與跨 repo override；`LEDGER-R-090` 正式歸 `open-4wd-pinning`。
- Specs 提供 owner-scoped checker；main 只驗自身 198 條，workspace 顯式聚合 main 與 pinning 後驗證 199 條。ghost 與 foreign-owner 標註硬紅，缺測仍維持 report mode。
- GitHub Actions 不集中 checkout 全部 implementation repo；待 Specs 公開並取得 immutable SHA 後，各 repo 只 checkout pinned Specs。

### 2026-07-29 ─ 文檔工程：signaling 常數改採 owner hard gate

> 決策檔：[D-20260729-02](../decisions/D-20260729-02-signaling常數owner硬閘.md)

- `open-4wd-signaling` 新增自身的 `check:constants`，由 `O4_SPECS_DIR` 或 sibling Specs 讀取程式參數表 §9，硬比對四個 server default；文件與 TypeScript 常數維持雙手編，不生成或 vendor runtime code。
- 值 drift hard fail，覆蓋缺口依既有制度 report-only，Specs 文件完全缺席則 fail closed。一般 signaling unit tests 不依賴 Specs，維持公版 template standalone。
- GitHub Actions 不 checkout main 或其他 implementation repo；待 immutable Specs SHA 可用後，只 checkout pinned Specs。

### 2026-07-29 ─ 文檔工程：CI 聚合與貢獻文件改採 package 權威

- Specs `docs-ci` 補齊 `test:docs`、`check:history`、`check:mermaid`，與 `package.json` 的 `scripts.check` 同序執行；工具鏈測試新增 parity 看守，防止後續新增檢查卻漏接 CI。
- 貢獻文件移除散落的九件／十五件硬編數字，改以 package 聚合及各 repo 貢獻指南的適用檢查為權威；文檔工程表完整列出現行聚合，workspace-only 跨 repo 檢查另列。

### 2026-07-29 ─ Pinning 部署：補齊 one-shot operator 變數權威

- Pinning 部署 canon 新增 Genesis one-shot 與 DMCA 案卷匯出的完整環境變數表，明定必填／選填、路徑隔離、receipt 原子發布、identity、release commit、store 獨佔與輸出優先序。
- Pinning README 保留可直接使用的命令與摘要，但明確回指 Specs §3.4 為規範性契約；工具鏈測試看守 operator 變數不得再從 canon 消失。

### 2026-07-29 ─ RWD：超寬遊戲面完成實作接線

- 主 repo 在 `120em` 起只對 Home Stage、Race Config Event Board 與 Room Start Gate 放寬內容面：由既有 `90rem` 隨 viewport 線性成長，最高 `112rem`；閱讀與工具頁維持原寬。
- 視覺矩陣新增 ultrawide 實際寬度斷言；Default 主題的三個 opt-in 狀態已於 3440×1440 Chromium 驗收並各自產出截圖。

### 2026-07-29 ─ RWD：低高度與 compact fit 門檻對齊

- 低高度橫向統一採 `orientation: landscape` 且 `max-height: 32rem`：shared app shell 壓縮 topbar 與頁面上下留白、隱藏非核心文字但保留 44px 控制，Landing 同步收合次要 hero 說明並保留主 CTA。
- Compact navigation 的權威改為 public shell `72rem` container content-fit threshold；移除未直接存在於程式的 768px／48em 裝置式常數描述，窄 viewport 與文字放大仍由同一 container query 涵蓋。

### 2026-07-29 ─ SEO／Pages：route manifest 與部署文件對齊

- SEO route manifest 補齊 `/watch/:id` 與 `/settings/:section`，22 個產品 route pattern 都有明確 metadata 契約；兩條 deep link 維持 `noindex`，觀戰頁補齊四語系 metadata。
- Angular prerender 文件改為實際的 `discoverRoutes: false` 加 `routesFile` 形狀，明載未前綴 public shells 與 `/login` 排除規則。
- Pages 流程改記錄 `configure-pages`／`upload-pages-artifact`／OIDC `deploy-pages`，不再誤稱部署到 `gh-pages` 分支。

### 2026-07-29 ─ UI：頁面標題、UGC 構圖與精密工作區一致化

- Issue 000075 核准並落地：UGC Browse 與 Race Config 改用共用標題，UGC Browse 移除 frame 角標；Result、Room 的所有 state 統一加入上下內容內距。
- `/ugc/:cid` 的 Part／Track 統一為 plain 置中構圖，只保留右側資訊與操作差異；Editor／Garage Edit 解除 `1440px` shell 上限，Editor 桌面工作台改填滿剩餘高度。
- 導覽列到共用標題的 `space-4` 距離改由 App shell 單一持有，頁面不再各自累加頂部 margin／padding；Default／月兔與 Chromium 多比例幾何測試同步看守。
