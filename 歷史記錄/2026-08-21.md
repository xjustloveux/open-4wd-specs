## 重大重構里程碑

### 2026-08-21 ─ 私有／公開 CI 與 Runner 分層

私有期的自動 CI 收斂為 master PR／push 的 GitHub-hosted Linux，Windows／macOS 實機改由
維護者對最新 master 手動執行；公開前另跑完整 hosted matrix，repository 轉 public 後由同一份
workflow 自動啟用標準 hosted 跨平台矩陣。self-hosted runner 離線不阻塞 required check，且公開
PR 沒有進入維護者機器的事件路徑。

> 決策檔：[D-20260821-01](../decisions/D-20260821-01-私有公開CI與Runner分層.md)

### 2026-08-21 ─ 私有 E2E 額度與 Linux argv 修復（issue 000745）

修正 Linux 上 package script 多餘參數終止符造成所有 E2E job 退化為五 project 全量執行的問題，
並以 executable validator 防止同類回歸。私有自動 E2E 收斂為 Ubuntu Chromium；全域 retry 改為
零、一般 timeout 改為 120 秒，失敗即保留 trace。Docker 僅作按需 Linux parity，不成為日常或
推版前置條件。

> 決策檔：[D-20260821-02](../decisions/D-20260821-02-私有E2E單線與Linux參數契約.md)
