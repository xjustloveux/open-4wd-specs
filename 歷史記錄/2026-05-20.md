## 重大重構里程碑

### 2026-05-20 ─ 材質系統 + 磁源 + thermal_limit 重構

> 決策檔：[D-20260520-01](../decisions/D-20260520-01-材質系統重構31種.md)

**動機**：對齊「可破壞性由建模決定」的核心原則；釐清磁源強度物理本質。

| 變動 | 細節 |
|---|---|
| `thermal_limit` 語意修正 | 改為「過熱閾值」（材料軟化/熔點溫度數值），是否觸發 broken 由建模決定，與材質本身無關 |
| 磁性身分重命名 | `is_mag_src` → `is_magnet_source`（純 bool 身分） |
| 磁源強度移層 | 從材質層移到建模層 Root Extras `magnet_source_strength_n`（0–10 N），未宣告 = 0 |
| Special-fluid 縮編 | 8 種 → 5 種；移除 `mercury` / `iron_sand` / `smoke`（主題違和或機制重疊）|
| 材質改名 | `liquid_nitrogen` → `freezing_fluid`（結凍液） |
| Deploy behavior 縮編 | 8 種 → 5 種；移除 `heavy_pull` / `ferromagnetic_field` / `vision_blur`，加中文對照 |
| 場景 entity 縮編 | 4 類 → 3 類；移除 `magnet_field`（任意 entity + 磁源材質 + Root Extras 強度 即可取代） |
| 算式表章節 cascade | §7 重力/下壓（mercury）整段移除 → §8–§22 全部 -1 → §7–§21；跨 12 檔同步更新交叉引用 |
| 全 spec 材質總數 | 34 → 31 種（14 vehicle + 12 environment + 5 special-fluid） |

**設計依據（磁源強度移層）**：

- 鐵磁材料的磁化率是材料固有屬性（電子組態決定）→ 留在材質層 `magnetic: 0-1`
- 主動磁源強度依賴特定物件的磁化處理 / 線圈電流 / 永磁加工 → 移到建模層

**物件「是磁鐵」條件**（兩者缺一無效）：

1. sub-mesh 材質 `is_magnet_source: true`
2. Root Extras `magnet_source_strength_n > 0`
