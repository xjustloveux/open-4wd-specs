**設計演化簡記**（B3 三輪）：

1. 初版（2026-05-27）：route = polyline；終點方向 = `RP(n-1) → RPn` 幾何；曲線靠多點折線逼近
2. 中版：route = Hermite spline；每點自訂 forward 切線；曲線從幾何切線插值
3. **定版**：spline + **RoutePoint 永遠貼 mesh 表面**；切線約束在表面切線平面（1 DOF）；up 軸自動 = surface normal；飛越段 spline 浮空 + b-soft 「在表面才檢核」物理 contact 判定 + 100ms hysteresis；採業界編輯器慣例（Trackmania / Forza track maker）

**核心設計決策**：

| 項 | 決策 |
|---|---|
| 識別 marker | `open4wd_version`（Root Extras，per-type 命名空間）+ `type` enum（8 零件 + track）；loader 三分支（無 marker 拒載 / track / 零件）|
| bump 原則 | 破壞性（增刪欄位 / 語意 / 演算法 / 必填無安全預設）→ 棄用；非破壞（純數值 / 位置）→ 只提示 |
| 生命週期 | 活躍 → 棄用（仍可用、含棄用件則該 type 全場降版本）→ unusable（picker 不出現、仍可被 fork）|
| 三升級分類 | ① 自動 / ② 需手動編輯 / ③ 無法升級 |
| 降版本運算 | 只換 per-asset「extras→物理輸入映射」、跑當前引擎、不綁 Rapier；不變式：跨資產聚合走 derive_logic（A 軸全場一致）；降版目標 = 最低非破壞相容類最高版；每破壞牆附雙向遷移（②人工有損存 pre-edit 快照）|
| 動態最低支援版 | 非靜態常數，ledger 衍生（`DEPRECATED_TO_UNUSABLE_THRESHOLD`=3、數「不同創作者」、單調 ratchet）；以 `deriveStateAt(checkpoint)` pin 進房算 |
| 共識 | 開房 pin ledger checkpoint，版本閘門對快照算、後加入 peer 須 sync、開賽前重驗 |
| 兩種提示 | 含棄用件→「降版本運算」（改物理，強）；混非破壞舊版→「數據可能有差異」（吃預設，軟）|
| 遷移流程 | schema 定於「上鏈提交時」（非編輯器開啟時）、落後先 shim；草稿 reload 後 shim；鏈式遷移可組合；版本 yank（壞版專用，唯一強推遷移）|
| 經濟 | 版本後繼升級上鏈免費（限真後繼）；版本後繼血緣（≠ fork）不新增分潤層，評分/使用次數/fork 樹位置三項在血緣節點層 aggregate |
| ledger | 新增 `AssetVersionUpgradeEvent`（新 CID → 舊 CID 後繼邊）；`AssetVersionDerivedState`（動態 min + 各 CID 版本狀態）|
| replay | 暫不實作；已知相依：未來加入需重訂舊路徑保留政策 |
