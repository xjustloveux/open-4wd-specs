## 重大重構里程碑

### 2026-08-24 ─ Pre-launch 公開 Q&A 延後至 Main（issue 000825）

Main 仍為 private 時，公開 Specs 與三個 service repo 的一般問題 contact link 無法形成單一、可達
入口。Specs Discussions 因此關閉，公開 repo 的 Issue Forms 移除一般問答連結；Main Discussions
保留給已獲權限的協作者預先整理。Main 轉 public 時，再一次同步五個 repo 指向 Main 的 `Q&A`
分類。安全通報維持獨立：公開 repo 統一連到 Specs 安全 canon，並在受影響 repo 使用 Private
Vulnerability Reporting。
