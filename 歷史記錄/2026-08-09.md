## 重大重構里程碑

### 2026-08-09 ─ 身分資產庫與 UGC 選擇器（issue 000223）

> 決策檔：[D-20260809-01](../decisions/D-20260809-01-身分資產庫與UGC選擇器.md)

UGC part／track 新增同一套 per-identity sealed 資產庫；入庫免費、只收 canonical CID，名單隨加密
本機備份但 bytes 不隨包。裝置投影只保存 CID reference count，不保存 owner mapping，並以獨立
`library` pin ownership 防止 GC；刪除身份在 profile 真正刪除後才減引用，未知匯入先 conservative。

Garage 與 Race Config 改以資產庫作正式候選權威，待取回項不可裝配或進 `MatchConfig`，可原地取回。
車庫 picker 在第 11 項起顯示搜尋，排序永遠可用，呈現來源、評分、縮圖與 stat chips；tire／roller
改為逐位裝配並跟隨 viewport mount 選取。`LOCAL` 標記統一套用於四個本機測試介面。

### 2026-08-09 ─ 社群 fork 手動一鍵部署（issue 000222）

> 決策檔：[D-20260809-02](../decisions/D-20260809-02-社群Fork手動一鍵部署.md)

signaling、turn、pinning 公版隨附 dispatch-only 部署 workflow，公版未設定
`DEPLOY_ENABLED` 與 secrets 時不會執行。營運者 fork 後填 Cloudflare Workers 或 GKE 的
secrets／vars，再手動 Run workflow；必要值 fail closed、外部 Actions 鎖完整 SHA。

signaling 預設 workers.dev 並成對注入 TURN bindings；turn 以真 STUN／TURN smoke 收尾；
pinning 在 checkout 外渲染 manifests，strict smoke 失敗即 rollback。TLS 分別由 Cloudflare edge、
cert-manager，與 `turns:` 選配的鎖版 reloader 管理。

### 2026-08-09 ─ Bootstrap 清單權威收斂（issue 000267）

> 決策檔：[D-20260809-03](../decisions/D-20260809-03-bootstrap清單權威收斂.md)

裁決以 D-20260803-06 的 community registry 作唯一專案隨附 bootstrap listing；玩家手動 entry
與已接受的 session multiaddr 維持較高優先來源。未接線的 `bootstrap/list.txt` 不再保留或補接
GitHub raw compatibility shim，歷史理由留在 ADR，runtime 僅保留 registry、快取與 build
snapshot 的單一消費鏈。

### 2026-08-09 ─ 玩家收藏與等待房授權快照（issue 000220）

> 決策檔：[D-20260809-04](../decisions/D-20260809-04-玩家收藏與等待房授權快照.md)

每個身分可本機保存最多 200 個玩家收藏；self／已封鎖對象不得加入，損毀與封鎖讀取失敗
fail closed。房主可在 waiting 建立一次性授權快照，同時略過 participant／spectator 密碼，
但不略過封鎖、容量、狀態、版本與角色守門，也不序列化、廣播、reload 或 succession。

### 2026-08-09 ─ 音訊槽位、UI Cue 與賽事空間音訊（issue 000224）

> 決策檔：[D-20260809-05](../decisions/D-20260809-05-音訊槽位UICue與賽事空間音訊.md)

UI、賽事與世界音槽位收斂為單一名錄，UI kit 透過最小 cue port，賽事事件由集中 router 映射。
世界音採原生 Web Audio、camera listener，`panningModel` 以 `equalpower` 起步並把 HRTF 留作後續選項；音訊只消費呈現位姿與事件，
不進 consensus、rollback、ledger、checksum 或 physics feedback。

### 2026-08-09 ─ Signaling Worker 改採 Socket Presence Liveness（issue 000277）

> 決策檔：[D-20260809-06](../decisions/D-20260809-06-SignalingWorker採SocketPresenceLiveness.md)

Node adapter 保留 transport ping／pong；Cloudflare Worker alarm 改以 hibernatable WebSocket
snapshot 判定 peer 是否存在。合法 idle socket 不再因沒有 application message 被回收，runtime
presence 消失後才套共同 timeout；不新增 client heartbeat 或平行 keepalive wire。

### 2026-08-09 ─ 效能回歸與 Bootstrap Coverage 改採可執行門檻（issues 000300、000301）

> 決策檔：[D-20260809-07](../decisions/D-20260809-07-效能回歸與BootstrapCoverage可執行門檻.md)

共享 runner 的效能 hard gate 改用校準 reference，惡化 10% 警告、25% 失敗；固定毫秒只作
診斷。Bootstrap adapters 由獨立 runner 量測 statements 50%、branches 45%、functions 35%、
lines 50%；未執法的 per-module 數字移除，release 必須實際執行 performance suite。

### 2026-08-09 ─ 跨 Repo Canonical Leaf Contract 與 Vendor Parity（issue 000282）

> 決策檔：[D-20260809-08](../decisions/D-20260809-08-跨RepoCanonicalLeafContract與VendorParity.md)

UGC content profile 與 Pinning API vocabulary 各自收斂為主 repo 的 canonical leaf，pinning
消費 manifest 鎖定的 vendored copy。Parity gate 驗 exact bytes、清單與完整 import closure，
不再以兩份手抄常數加 drift assertion 冒充單一權威。

### 2026-08-09 ─ 應用字型改採 Locale-Aware 延後載入（issue 000271）

> 決策檔：[D-20260809-09](../decisions/D-20260809-09-應用字型LocaleAware延後載入.md)

Inter 與共用樣式保留 initial；繁中、簡中、日文各自的 400／700 自站字型只由目前語系啟用，
切換時替換唯一 active stylesheet。英文不下載 CJK，固定 `font-display: swap` 並接受短暫 FOUT，
失敗回退 locale stack 而不阻擋 app 或語系切換。

### 2026-08-09 ─ Editor 禁止 Barrel 並改採責任 Leaf Import（issue 000264）

> 決策檔：[D-20260809-10](../decisions/D-20260809-10-Editor禁止Barrel並採責任LeafImport.md)

Editor 的 browser、Worker 與 Node-only 壓縮依賴不得再由 `src/editor/index.ts` 混合；production
與 tests 改按責任 leaf-pick，共享型別下沉無 runtime dependency 的 leaf type module。Import
boundary 同時禁止 consumer 並要求 retired barrel 實體不存在。
