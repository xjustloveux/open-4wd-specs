### 2026-06-28 ─ 武器 multi-actuator 統一模型整進 canonical（機制定案、UI 留草案）

> 決策檔：[D-20260628-01](../decisions/D-20260628-01-武器multi-actuator統一.md)

承「兩邊各自獨立旋轉武器」討論：經多輪設計收斂，把武器 `general` 機制**統一**為 **`weapon_actuators[]`**（一組獨立驅動 pivot，每項 payload = 剛體轉子 `mesh_node` 或鏈條 `chain`）。**單轉、多轉、單鏈、多鏈全是其特例**。使用者裁定**機制 / 參數現在定案進 canonical、只有編輯器 UI 留草案**（綁整體版面 A1）。

**核心設計**：

- **轉速 energy-driven + 守恆**：`ωᵢ = P × K_WEAPON_ROTOR_SPEED × (speed_weightᵢ / Σ speed_weight)`，`P = kinetic_ratio × battery.declared_output_w`。`speed_weight` 預設 1 → 均分 `1/N`；加 actuator → 各自變慢（**總功率守恆、無 exploit**）；耗能/發熱不隨數量變（仍 ∝ applied_energy、由 kinetic_ratio 決定）。
- **鏈條 = actuator payload**：基座旋轉吃 speed_weight、**尾段 `Chain_Segment` 物理 joint 甩動不吃**（使用者澄清的「後面帶動的揮甩」）。
- **共用單一觸發**（晶片 1 weapon 槽）；獨立的是運動、非觸發。kinematic 預定運動（非 joint+motor）；同武器各 actuator 間關碰撞。
- **反作用力**：weapon-level 沿 `Axis`（多 actuator 共用 `applied_energy`、淨值不變、同既有線性簡化、不模擬轉向 recoil 抵銷）。放開：360 減速停 / <360 回歸原位。`motion_curve` 無 `step`。

**常數**：新增 `MAX_WEAPON_DRIVEN_PIVOTS`(8) / `K_WEAPON_ROTOR_SPEED`；`MAX_CHAIN_SEGMENT`→**`MAX_WEAPON_DRIVEN_BODIES`**(16、= 剛體轉子 + 全鏈段總數、走 a 總數封頂給「一短一長」自由)。**body 預算不變**（8×16=128 保留額沿用，只改標籤）。保留 `weapon_max_angle_deg` 名（移進 actuator、不另改名省 8 檔 churn）。

**落檔**：建模 §3.7（schema + scene graph）/ §5.2 / §5.3 / §4.3 `auto_chain`、算式表 §3（轉速、連帶釘單轉子揮速）/ §4（反作用力加總）、程式參數表 §3（caps + rename）/ §18（K）/ §2（預算 + assert）、零件與場景 §9.2、程式架構/interfaces（`WeaponActuator`）、編輯器操作 §3.2（單 actuator 沿用 + 驗證 + 多 actuator UI 指草案）、UGC機制 / UGC上傳流程（欄位 + 檢核）、builtin-assets §5、其他.md §5/§10、其他/武器多轉子.md（瘦身成 UI-only 草案）。
**殘留（壓後）**：asset-image-prompts §8.2「general_rotate」術語（art prompt、視覺等同 1-actuator、隨該檔壓後複審清）。
**整合後自我 review 修 4 處（整合自造）**：`weapon_main_mesh_node` desc「操作 mesh」→「不轉本體 / 基座（hub）」、反作用力改 weapon-level、§3.7.1「左 / 右 slot」舊措辭、`auto_empties` 多 Pivot。**2 可重議判斷（已報備、使用者可推翻）**：① **反作用力 weapon-level**（沿 Axis、不模擬反向雙臂 torque 抵銷；若要抵銷須改逐 actuator 拆向）② **`weapon_main_mesh_node` 對 general_actuated 仍必填當基座 / hub**（若要允許「純 actuator 無基座」武器則改可選）。
