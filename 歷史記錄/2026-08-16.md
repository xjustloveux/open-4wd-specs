### 2026-08-16 ─ 待辦索引回歸純索引（issue 000607）

`其他.md` 不再保存已定案的五項規則、常數名值副本、已落地的 catch-up 規格、已消失的 settlement
base lag 模型或 vendored 檔數快照。待校準參數以程式參數表逐 row 的「初估／暫定／待 playtest」
標記為唯一登記面；本檔只補公版整體配置與介面公差兩類跨 row 校準工作。

尚待研究的機制收斂為仲裁激勵、`canFileReport` 自佔告位與編輯器幾何工具精修。發布工作則精確
對映專案生命週期第 6／10 步與 workflow issues 000051／000053；main private 期間 local-only CI
應通過，不再誤稱整體 CI 必紅。原五項規則保留在各自 canon，並移除依賴待辦檔編號的「鐵則 N」
標籤。

### 2026-08-16 ─ ADR 廢止關係改採必填 metadata 與生成索引（issue 000606）

停止把停在 2026-06-12 的手工廢除欄位表宣稱為完整權威；該表與早期規格、版本對齊附錄凍結為

具名移除、改名與取代關係，共回填 104 筆；不從被否決選項或一般 prose 自動猜測。

`check:decisions` 現在驗證 metadata schema、要求新 ADR 即使無項目也明寫空陣列，並由同一來源
生成決策索引。schema／generator guard 與歷史回填分兩個驗證階段完成，但同屬一次交付，只有
全部回填並通過完整 specs 檢查後才視為完成。

### 2026-08-16 ─ 封鎖衝突改採房內本機警示（issue 000564）

公開房間廣告繼續維持不含 participant roster 的隱私投影，不為封鎖預先揭露名單。房主仍可用
自己的本機清單拒絕加入並回通用原因；其他 client 只在接受初始或後續權威 roster 後計算本機
交集，命中時持續顯示私人警示與一鍵離房，不自動離開、不要求踢人，也不向全房廣播。等待房
自行離開無懲罰；賽內倒數與 GO 不重做這項裁決。

### 2026-08-16 ─ PeerId 顯示身分與暱稱快照消歧（issues 000566、000567）

所有遠端人物以已驗 PeerId 為唯一身分權威，暱稱只保存發送或 admission 當下的非唯一呈現
快照。共用 resolver 顯示合法暱稱加 `#` 與穩定短指紋；無暱稱只顯示指紋。短指紋取完整 PeerId
的 SHA-256 前 4 bytes，而非截取常有共同前綴的 PeerId 字串。profile、room wire、聊天、觀戰、
近期隊友與封鎖清單共用同一 canonical nickname validator 與 resolver。

> 決策檔：[D-20260816-03](../decisions/D-20260816-03-PeerId顯示身分與暱稱快照消歧.md)

### 2026-08-16 ─ 本機文字顯示過濾與 starter 匯入（issue 000576）

聊天完整原文照常簽署、傳送、保留及匯出為檢舉證據；每位玩家只在自己的裝置 render copy 套用
可開關、可編輯的 literal 詞表。詞表採有界 Unicode-aware substring 與來源位置映射，不接受任意
regex。Git 可提供四語 starter list，但只有玩家在設定頁明確複製才建立本機副本，後續更新不得
自動加入、刪除或覆蓋玩家設定。

> 決策檔：[D-20260816-04](../decisions/D-20260816-04-本機文字顯示過濾與starter匯入.md)

### 2026-08-16 ─ 賽事空間音訊正式採 HRTF

### 2026-08-16 ─ Fork 修改幅度與反複製相似度分離（issue 000589）

宣告 fork 的 10% 最小修改幅度統一採 per-type `PhysicsFingerprint` diff，且只在相同
`fingerprintVersion` 間比較；跨版本 pass-through。mesh 幾何指紋及算式表的 0–100 相似度只
服務反複製分流：≥90% 拒收、70–90% 進 `similarity-pending`，不再兼任 fork 修改門檻。

### 2026-08-16 ─ Active magnet 場強採 SOC 降額後功率（issue 000590）

active magnet 場強統一為 `available_output_w × allocation_pct / 100 × K_MAGNET_FORCE`，與其他
武器／技能共用低 SOC 線性降額後的功率預算。這同時補回 allocation 百分比的 `/100`，避免舊式
configured output 直乘造成最多 100 倍場強，並同步算式、材質、建模欄位與鐵則備忘。

### 2026-08-16 ─ Pre-launch 自有 current 版本 gate 補齊（issue 000584）

機器可讀 authority 清單新增 asset schema、PhysicsManifest、SavedState、builtin assets、checkpoint
與統一 IndexedDB 六類 current baseline，並把 `check:prelaunch-versions` 納入完整 package check 與
Docs CI。第三方標準版本與歷史 ADR 仍不屬於 current baseline 掃描範圍。

### 2026-08-16 ─ Conformance fixture 格式與內容修訂史分離（issue 000608）

12 個 conformance 家族統一使用 `formatVersion: 1` 的 envelope，不再保存 fixture 編輯次數；案例
與 expected 的歷史改由 Git、exact specs SHA、綁定 ADR 與 `generatedBy` 追蹤。家族索引改由
fixture metadata 生成，新增完整性 gate 驗證 family 路徑、spec、encoding、provenance 與案例名稱。

### 2026-08-16 ─ Pre-launch canon 移除未發布相容敘述（issue 000621）

### 2026-08-16 ─ UGC Presentation Metadata 採獨立簽署 Revision（issue 000597）

UGC 的名稱、描述與 tags 從 immutable admission metadata 拆出：upload 建立 presentation revision 0，
後續由原作者另簽 `ugc-metadata-update` 作 exact CID 的 full replacement。原 GLB、CID 與 upload
簽章不改；更新只接受下一 revision、成功更新間隔至少一小時，blacklisted CID 禁止更新。
預設免費，未來非零費率時 burn 與 revision 原子套用；current checkpoint 必填 presentation、
revision 與 updatedAt。事件 allowlist 因此成為 20 種，並同步 pinning vendor exact schema。

### 2026-08-16 ─ 熱源、積分與輪胎熱磨耗單一化（issue 000595）

熱模型統一為 per-part J／W ledger 後單次 backward-Euler 積分：chip／battery skill 廢熱皆由
實際 `battery_cost_j` 乘現行 waste-heat 常數，burn／freeze 先乘 heat capacity 轉成 W，不直接
修改溫度。Chip 殺手鐧改在積分後以 `T_next > thermalLimitC` 判定；motor、ambient、clamp 常數名
與實作一致。Tire／roller 明列接觸導熱與 slip heat，熱磨耗採二次有界 1→3，不再使用線性 1→4。

### 2026-08-16 ─ 物理步進、Solver 與公開介面收斂（issue 000596）

### 2026-08-16 ─ 建模、場景與本機資料 current shape 對齊（issue 000619）

### 2026-08-16 ─ 觀戰公開 payload 與 room 暱稱快照收斂（issue 000599）

fallback HUD wire 的 standings 收斂為 `peerId` 與 `rank`，不再重複公開暱稱；viewer 只從已驗

### 2026-08-16 ─ GO 後主動離場統一為本人單簽成本（issue 000600）

主動離場統一先送 `leave`（`reason: voluntary`），再 best-effort 上鏈本人單簽
`RaceLeaveEvent`；事件只立即套用本人 `disconnectCounts +1` 與信譽 −5，不產生排名、
TrueSkill、經濟或完賽效果，也不縮小 MatchResult quorum。異常斷線仍由合法
`MatchResultEvent.disconnects` 推導相同離場效果；兩來源共用持久 `(matchId, peerId)`
去重鍵，任一到達順序或重播都只計次、扣分一次，無 quorum 時不得由少數替第三人處罰。

### 2026-08-16 ─ Bootstrap、Genesis trust root 與網路上限收斂（issue 000613）

移除不存在的 `BOOTSTRAP_NODES_MIN` 與 private／public 至少一節點 gate；空 bootstrap 清單
維持合法本地／既有 session 模式，`BOOTSTRAP_NODES_RECOMMENDED = 3` 只作獨立故障域可用性提示。
Client build profile 與 pinning 部署面補齊 receipt `genesisTimestamp`／`GENESIS_TIMESTAMP` 必填
trust root，formal stage 缺值、0 或本機啟動時間都 fail closed。Signaling 單房 `MAX_PEERS = 64`
登錄至伺服器常數權威；升版流程統一 client cache 版本、編譯期值來源、development island 與
`/version.json` 失敗語意。

### 2026-08-16 ─ 前端實作 canon 與 runtime 契約收斂（issue 000614）

PWA／App Shell 文件改採 `locked`、`launching`、`local-ready`、`reconnecting`、
`online-ready` 五態與原子 capability snapshot，不再用三層 offline tier 猜功能。i18n 統一為
19 個 root、lazy bundle chunk、settings 保存後提示重整，以及只載入目前 CJK 語系的 locale font；
主題靜態資產不再誤類比 i18n，render profile 補齊舞台六色、降級原因與保留 SFX 正名。

Settings 文件同步跟車距離、收藏清單、聊天顯示詞表、本機安全事件 JSON 匯出與八大正式分類，
移除 issue 指涉與可覆寫 reduced-motion 係數的錯誤說法。公告 build 明確直接執行 generator，
`check:announcements` 仍如工具鏈 inventory 所載為可供本機／PR 使用的 local check，而非已存在的
