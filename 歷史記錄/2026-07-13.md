## 重大重構里程碑

### 2026-07-13 ─ 公開上線 hardening、三階部署狀態與安全資料邊界

> 決策檔：[D-20260713-01](../decisions/D-20260713-01-三階部署狀態.md)

轉為 public repository 不以 GitHub Release 為前提；`release-readiness` 是維護者在
轉 public 前手動執行的 gate。部署狀態分 development、private-playtest 與 public：
private-playtest 可先用一個 bootstrap，但必須有正式 ledger 與一位治理 signer；
public 至少要求一個合法 bootstrap，少於三個以單點故障警告呈現，三個以上才是建議
冗餘，不把資金有限的初期部署硬擋在三節點門外。`LEDGER_DB_ADDRESS` 是 genesis 建立
`open4wd-ledger` 後取得的完整 OrbitDB address，不是任意名稱；一般 client 缺 address
時不得自行同名建庫。

TURN credential 從一般 NetworkSettings 明文列移至 PIN 衍生加密 secret store，
runtime 建連線時才短暫解密；空白輸入代表保留，清除走獨立操作，失敗不得覆寫。房間
responder 綁 discovery 得到的預期 host PeerId，offer 前 ICE 只在有界 per-peer buffer
暫存；RoomWire／spectator JSON 以完整 discriminated-union parser 驗所有欄位與 byte
上限。IndexedDB readwrite 只能在 transaction `oncomplete` 後更新記憶體狀態；
settings load／update 共用 sanitizer，`resetAll` 是單一 transaction。Pages／PWA／SEO、
project-path deep link、GLB manifest hash／CID／extras／assetsVersion 與 Stage 3
validator 同步成 release gate；當時允許的外部 blocker 只有 27 個正式 GLB 及真實
ledger／signer／bootstrap／signaling／pinning 值。

### 2026-07-13 ─ 遊戲 UI 美術方向由系統介面轉為專業迷你四驅車工坊

> 決策檔：[D-20260713-02](../decisions/D-20260713-02-美術方向工坊翻案.md)

第一輪曾核准「克制的機械競速」方向，以深色中性表面、Track Bracket、SVG icon 與
資訊層級取代 emoji／系統卡片牆；實際截圖驗收後仍被判定太像管理系統，因此該方案
保留為歷史但不再是實作權威。現行方向改為「專業迷你四驅車調校工坊」：車輛／賽道
舞台是第一焦點，Stage、Pit Board、Tool Drawer 分層，一個畫面只突出一個主要 CTA，
技術欄位收進工具抽屜，避免企業 dashboard 密度與一般賽車比例。

為確認參考圖能否高還原，先建立獨立 HTML／CSS 樣板；靜態材質、面板與構圖由 DOM／
CSS 負責，複雜美術才拆成可裁切圖層，禁止把完整 UI 截圖烘焙成背景。原型曾採 Canvas
2D 合成車、光效、粒子與視差，Canvas 不承載文字或操作；後續驗證多 GLB 組裝可行後，
正式版改由 Three.js 顯示車輛，Canvas 原型只留作歷史。圖示統一 SVG 而非字元／emoji，
音樂音效 slot 可先為 `null` 並安全 no-op；桌機、平板、手機與方向切換皆須保留首要
操作、44 px 觸控目標、focus、reduced-motion 與零 document 水平溢位。
