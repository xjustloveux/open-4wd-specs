## 重大重構里程碑

### 2026-08-23 ─ TURN 渲染後 conf 改以 Secret 承載（issue 000788）

turn 公版 k8s 部署原把 envsubst 渲染後的 `turnserver.conf` 建成 ConfigMap，而模板的
`static-auth-secret` 會把 shared secret 真值渲染進同一檔案；另以 `--from-literal` 建立的
`open4wd-turn-secret` 沒有任何 workload 消費。首推前 push-safety 掃描確認後，deploy workflow
改以 Secret `open4wd-turn-conf` 承載整份渲染檔並掛成 `/etc/coturn/turnserver.conf`，不再建立
ConfigMap 也不再注入 `open4wd-turn-secret`；後者降為營運者手動維護的 TLS 鍵 Secret。
部署資訊/open-4wd-turn.md 的 §0／§2／§4／§5／§6 同步改寫。

### 2026-08-23 ─ 註解 hook 改為本機 wrapper 生成（issues 000744、000789、000791）

主 repo 於 2026-08-21 因 Windows 重建 `.git` 後 `.githooks` 可執行位遺失、Linux CI 紅燈，已把
opt-in 註解 hook 改為 setup 在目前 clone 的 `.git/hooks` 生成 0755 wrapper、不再設定
`core.hooksPath`；pinning、signaling、TURN 三個 Template 的 `.githooks` 同樣以 100644 入庫而
POSIX clone 會靜默略過，遂比照移植同一設計並補齊 setup 測試。決策檔 D-20260815-02 原文仍寫
「setup 只寫 local core.hooksPath」，以 amends 決策補正，不改舊檔本文。

> 決策檔：[D-20260823-01](../decisions/D-20260823-01-註解hook本機wrapper生成.md)

### 2026-08-23 ─ specs lock 靜默過時補非阻斷 drift 訊號（issues 000796、000797）

消費端釘定 specs 不可變 commit 的代價是「specs 前進而沒人改鎖」只會靜默過時、不會紅燈。
main、pinning、signaling 各加一支排程、唯讀、不阻斷的 `specs-lock-drift` workflow：checkout 釘定
commit、fetch specs master、只對該 repo 實際消費的內容差異發 warning 與 job summary。main 的
文件型消費者（toolchain.md、程式架構.md、testing.md）只比對實際讀取的 toolchain 表與 §4／§9／§5
章節，散文修訂歸入 prose-only 不提醒；資料型路徑仍整檔比對。專案生命週期 §2 對照表後補記此訊號
不取代表內判斷、改鎖仍整組重推導。
