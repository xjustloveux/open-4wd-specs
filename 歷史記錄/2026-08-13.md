## 重大重構里程碑

### 2026-08-13 ─ 註解語言與公開 Template CI 劃界（issue 000468）

主 repo 保留官方上游的繁體中文註解硬閘，但將語言政策與語言中立的品質檢查拆開，fork
建置不再承受官方語言偏好。Pinning、Signaling、TURN 是供第三方自行維護與部署的公開
Template，不加入註解語言 CI 或部署前置；第一方註解接受英文或繁中，vendor 保留來源語言。

> 決策檔：[D-20260813-01](../decisions/D-20260813-01-註解語言與公開Template-CI劃界.md)

### 2026-08-13 ─ 規則 owner 單一責任契約（issue 000475）

`implementationRepos` 保留陣列格式，但每條規則只允許一個 owner，讓 schema 與既有
owner-scoped coverage／conformance 模型一致。真正需要共同執法時另立逐 repo 的新版契約，
不讓任一 repo 的證據替其他 repo 補 coverage。

> 決策檔：[D-20260813-02](../decisions/D-20260813-02-規則Owner單一責任契約.md)

### 2026-08-13 ─ Specs CI 外部 Action 不可變鎖定（issue 000476）

Docs CI 的 checkout、pnpm setup 與 Node setup 改鎖完整 commit SHA，並新增 workflow policy
checker 接入本機聚合與 CI。最小權限與 frozen lockfile 繼續保留，但不再被誤當成外部 Action
版本不可變的替代品。

> 決策檔：[D-20260813-03](../decisions/D-20260813-03-Specs-CI外部Action不可變鎖定.md)

### 2026-08-13 ─ ADR 路徑與向量家族識別（issue 000478）

ADR `files` 定義為安全但不要求現存的歷史 repo-relative path；`vectors` 統一使用向量檔內的
穩定 family ID，且必須恰好解析到一份 conformance 向量檔。既有 path-valued metadata 依 family
回填，accepted ADR 本文維持不變。

> 決策檔：[D-20260813-04](../decisions/D-20260813-04-ADR路徑與向量家族識別.md)
