## 重大重構里程碑

### 2026-05-22 ─ 材質表欄位簡化（移除 impact + 磁性 schema 合併）

> 決策檔：[D-20260522-01](../decisions/D-20260522-01-impact廢除磁性合併.md)

**動機**：審計材質欄位是否有可整合簡化的冗餘欄位。

| 變動 | 細節 |
|---|---|
| 移除 `impact` / `impact_toughness` 欄位 | 全 spec / 算式表均無公式引用該欄位，純為材料學註記、遊戲機制完全用不到 |
| ceramic desc 微調 | 「衝擊韌性極低」→「易碎裂」（呼應廢除欄位）|
| 磁性 schema 合併 | `magnetic` + `is_magnet_source` → `magnetism_role` enum（`source` / `passive` / `none`）+ `magnetic_susceptibility`（僅 `passive` 時用）；型別系統強制互斥取代額外 schema 檢核 |

**磁性合併設計**：

- `magnetism_role: 'source'` ← 原 `is_magnet_source: true`（純身分；強度仍由 Root Extras `magnet_source_strength_n` 決定）
- `magnetism_role: 'passive'` + `magnetic_susceptibility: 0-1` ← 原 `magnetic > 0`（被動鐵磁感受性，材料固有屬性）
- `magnetism_role: 'none'` ← 原 `magnetic: 0` + `is_magnet_source: false`（多數材質）
- 表格 cell 數不變（19 欄）；§8 從「互斥二分」改為「三選一身分」

**評估結論**（其他不動）：

- `forbidden_scopes` + `allowed_part_types` 不改 enum（保留未來擴展彈性）
- `is_fluid` 不由 `deploy_behavior` derive（語意分離）
- `k` / `c` 不可合成（散熱與蓄熱物理不對稱）
