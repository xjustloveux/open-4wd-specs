## 重大重構里程碑

### 2026-07-15 ─ 完整 Review 遺漏修復、部署 trust root 與真實設定 consumer

正式部署的 `governanceSigners` 不只由 release script 驗值，還必須沿
`app.config → App Shell → createApp → assembleLedger` 進入 genesis、DerivedState、
config update 與 checkpoint 的同一 trust root；一位 signer 可作初期治理、兩位非法、
三位以上採 `floor(2N/3)+1`。readiness 以唯讀 stage／mode／errors／warnings 暴露，
Pages 驗證與 production build 使用同一 stage，避免「檢查 public、bundle 卻仍是
development」。Three.js canvas 的 CSS 尺寸由 component 直接約束在 stage content box，
backing buffer 才依 DPR 放大，並以 DPR 2 驗證桌機與行動瀏覽器。

主題切換採 latest-wins generation：候選 theme 載入與驗證成功後才持久化，失敗保留
現況；成功後音訊重新解析目前 slot，SSR 與 browser 共用 base-aware asset resolver。
`effectsQuality`、自訂按鍵、遊玩時間提醒、PeerId／CID 隱私、IPFS 貢獻與 pinning nodes
都必須接到真實 consumer；Provider 未注入時顯示未啟用，不得模擬網路成功。Default
主題 install-time precache、其他主題 lazy cache-first；build 不公開 TypeScript 原始檔。
Modal 補齊 focus trap、Escape、初始／復原焦點及可翻譯名稱。正式 GLB 缺席時採明確的
工坊藍圖／組裝預覽，不以低模方塊冒充完成品；README 與外部部署值仍延後。

### 2026-07-15 ─ 車庫雙主題背景美術、藍圖與 runtime 資產管線

Default 與月兔背景定為同一桌上型迷你四驅車調校台的配對重製：前者是半寫實專業工坊，
後者是中度 Q 版日系中秋工坊；共用相機、工作桌高度、中央 GLB 安全區與景深，但不是
單純換色。背景不得烘焙車、品牌、文字、按鈕或 UI。1920×1080 sRGB PNG 母檔保留在
規格美術資源供後續裁切調色，runtime 只引用逐張檢查品質的 WebP；Default 隨 PWA
預快取，月兔 lazy cache-first。單張中心安全構圖先服務桌機與手機，只有實機證明不足時
才增加行動版資產 key。

早期核准稿要求依 105 mm 車寬、115 mm 車道與 50 mm 牆高繪製右側局部雙線軌道，
也保留 Scale Rail／尺寸標註，以處理先前「真車賽車工坊」比例問題；多輪視覺驗收後，
軌道比例仍容易誤導，最終決定移除背景軌道、量測尺標、遠景人物與工作區，避免任何
不準確的尺度宣稱。藍圖也由近乎實色、覆蓋整舞台的方格稿改為透明工程投影，之後再
依無刻度決策移除數字與單位；正式 GLB 載入後完全不覆蓋格線。`theme.json` 是 garage
色彩與資產的權威，SCSS 不得重設 Default 值；月兔 accent 是可響應定位、不可互動的
獨立裝飾，Default accent 為 `null`。
