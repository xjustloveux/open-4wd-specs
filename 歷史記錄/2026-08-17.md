## 重大重構里程碑

### 2026-08-17 ─ 網路常數改採原生語意與故障域觀測（issue 000650）

DHT query-self 與 GossipSub mesh、heartbeat、gossip／publish／graylist 門檻改由 libp2p adapter
明示傳入原生選項；錯名或沒有公式映射的舊常數直接退場。原帳本 replication 數量改成 bootstrap
與健康 pinning provider 的 best-effort 獨立故障域觀測，少於三個只在設定頁提示，不阻擋本地、
離線或單節點啟動，也不構成留存與恢復保證。版本相容不再保留無行為的模式開關，直接維持
client major 相同、其餘版本欄位全等的唯一規則。

> 決策檔：[D-20260817-02](../decisions/D-20260817-02-網路常數改採原生語意與故障域觀測.md)

### 2026-08-17 ─ 比賽執行常數與賽前窄路警告收斂（issue 000651）

正式倒數改讀 race/gameplay 的 1000 ms 節拍，不再借用 UI 動畫常數。固定 60 Hz 的 dt 只由
`1 / FIXED_FRAMERATE_HZ` 精確推導，純 rollback 不另設零 input-delay 常數；沒有決定性超限
處置的碰撞對數也退場。rollback 邊界與整場 rigid-body 預算保留為 CI invariant，不在 runtime
重複設閘。

場地 admission 會將 canonical GLB 的有效最窄路徑投影到 typed manifest；race runtime 不重新解析
raw extras。賽前會將本車所有零件的 AABB 八角套用 mount matrix 後聯集 X 寬度，再加 5 cm
安全餘裕比較；超寬只顯示本機提示，仍可正常開始比賽。

> 決策檔：[D-20260817-03](../decisions/D-20260817-03-比賽執行常數與賽前窄路警告收斂.md)

### 2026-08-17 ─ UI 常數權威收斂至實際消費端（issue 000652）

共用響應式權威收斂至 CSS／SCSS 的 40em／64em／90em 級距與 script gate；編輯器僅保留
用途導向的 `(width < 64em)` compact query，不再維護 TypeScript px 對照。現行 fluid／水平 rail
版面未使用的固定 header、sidebar 與 garage grid 數值一併退場。

Effective reduced motion 延續靜態素材、0.01ms 與停用 smooth scrolling，不乘折扣係數。首發不做
loop route 舒適帶與圈速預估，也不留常數接縫。品牌直接使用 `app.tagline`，未使用長版文案刪除；
sitemap 與 robots output path 只由 SEO generator 擁有。

> 決策檔：[D-20260817-04](../decisions/D-20260817-04-UI常數權威收斂至實際消費端.md)

### 2026-08-17 ─ EconomyConfig 收斂為單一 runtime authority（issue 000654）

Ledger、治理 fold 與 runtime 讀點原本已統一使用 `src/economy/config.ts` 的 `EconomyConfig` 與
`GENESIS_ECONOMY_CONFIG`；system-constants 內另一份只供局部 invariants 使用、且 shape 與金額型別
有意不同的 frozen defaults 退場。rev-share、governance signer 與完整 shape 改由真正 runtime
authority 的 validation／tests 守門，pinning vendored source 同步相同邊界。

> 決策檔：[D-20260817-05](../decisions/D-20260817-05-EconomyConfig單一Runtime權威.md)

### 2026-08-17 ─ Sanitize 與文字過濾只保留可執行 authority（issue 000653）

瀏覽器沒有可攜的 per-worker heap 硬上限；sanitize 記憶體防線改由解碼前輸入大小、文件／
collection／幾何／extras 結構天花板與逾時終止共同表述，不再宣稱未被 runtime 強制執行的
固定 MB 配額。聊天的 normalized literal substring 與 DMCA 每筆 `exact`／`substring`／`regex`
模式維持既有行為，但移除兩邊都沒有讀取的全域 match-mode 常數。貢獻觸發率上限則保留為
跨所有 `ugcCacheUsagePolicy` 的 CI invariant。

> 決策檔：[D-20260817-06](../decisions/D-20260817-06-Sanitize與文字過濾只保留可執行權威.md)
