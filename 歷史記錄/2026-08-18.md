## 重大重構里程碑

### 2026-08-18 ─ Authoring 大型原始資產 Release-first（issue 000658）

GLB、高解析／無損 PNG 與 WAV／FLAC authoring master 改由 specs immutable GitHub Release
作唯一長期 bytes 權威，不再依賴 Git LFS 額度。受版控的 prepare 與 publish BAT 將離線封裝、
人工審查、Draft 上傳、下載回讀與不可變發布拆成明確階段；exact tag 確認前不會發布。大型原始
備份只有在 Release 回讀、receipt 留存與 main adoption 全部成功後才可移除。

> 決策檔：[D-20260818-01](../decisions/D-20260818-01-Authoring大型原始資產Release-first.md)

### 2026-08-18 ─ Graphify 跨 repo immutable Release 聚合（issue 000659）

四個產品 repo 改為各自發布綁 exact source SHA 的 immutable Graphify Release；specs 從固定
allowlist 獨立驗證每個 repo 最新有效成品，允許部分成功並明示 missing／private／fetch-failed／
invalid。來源 workflow 以只安裝於 specs 的 GitHub App 喚醒刷新，payload 不作資料來源；手動與
低頻排程提供復原路徑。只有 `graph.json` 的 pinning／turn 亦可在本機建站顯示，統計不再硬編碼。

> 決策檔：[D-20260818-02](../decisions/D-20260818-02-Graphify跨RepoRelease聚合.md)

### 2026-08-18 ─ 文檔站首頁狀態與精簡導覽（issue 000662）

文檔站改由首頁一般內文明示開發中狀態並連回生命週期權威，內頁不再重複 lifecycle banner、
更新時間與 specs commit。分類子頁與程式流程標題移除可由所在位置得知的前後綴；只有 README
的子分類在導覽攤平，Conformance 測試向量與知識圖則提升到首頁之後。

> 決策檔：[D-20260818-03](../decisions/D-20260818-03-文檔站首頁狀態與精簡導覽.md)

### 2026-08-18 ─ UGC Presentation canonical clock 投影（issue 000643）

Presentation revision 的 live admission 與 UI preflight 改為投影 fold 將採用的
`max(mirrorHead.derivedAt, event.timestamp)`，避免低流量時 mirror clock 停滯造成作者自鎖；
revision 0 也以 upload 套用時的 canonical `state.derivedAt` 建立冷卻錨。timeless replay 仍不能以
倒填 timestamp 讓 clock 倒退，live／full fold／refold 因此採同一裁決。

> 決策檔：[D-20260818-04](../decisions/D-20260818-04-UGCPresentationCanonicalClock投影.md)
