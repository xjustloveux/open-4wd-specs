> 決策檔：[D-20260704-01](../decisions/D-20260704-01-主題系統三件套.md)

**動機（使用者提案）**：樣式／圖檔／圖示／LOGO／音樂與程式碼**脫鉤**——程式碼只保證流程與功能（只認 token 名與資產 key），外觀交給主題；個人選單選主題、主題可分類、逐主題留歷史（社群討論與累積的分辨單位）。討論兩輪定案：

- **模型**：token（CSS custom properties＋資產 key）＋ manifest（`theme.json`：id／內嵌多語系 name／category／authors／version／tokens／assets）＋ **fallback**（主題只放要覆蓋的、缺項 runtime 落 default——同 i18n 缺 key 邏輯；default = fallback 骨幹、CI 驗完備、SW install 預快取；其他主題 lazy、首載不含）。
- **⭐分類 = 資料非程式 enum**（使用者裁：分類現在無法確定、必須可變更）：`categories.json` 註冊表（id＋i18nKey，顯示名走 dict `themes.category.*` 四語系）；**起始僅 `basic`**，累積後 PR 加分類＋改各主題 category 欄（演化 = 純資料 patch、零程式變更；分類變遷留各主題 git 歷史）；粒度不限（「端午節」下逐年 `duanwu-2026`…永久可選）。機制一次完整、演化的是資料（非功能分期）。
- **⭐資產依主題隔離**（使用者裁）：`themes/<id>/` 自包含、磁碟零混放；共用靠 fallback、**禁止跨主題引用**；validate 雙向查（引用檔案存在＋資料夾檔案全被引用防垃圾）。
