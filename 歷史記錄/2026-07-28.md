### 2026-07-28 ─ Ledger genesis 與 replica bring-up

> 決策檔：[D-20260728-05](../decisions/D-20260728-05-Ledger-Genesis-Bring-up.md)

- 正式 `open4wd-ledger` 的建立從瀏覽器與正常 service 分離，收斂為 pinning repo 的獨立 one-shot operator；正常 service 仍硬性要求 exact `LEDGER_DB_ADDRESS`，不得依名稱 fallback。
- Genesis 使用專用持久 identity／空資料目錄與 1 或至少 3 位治理 signer，成功以 exact address 重開驗證後才發布不含 secret 的 receipt。Genesis provider 保持可達，直到不同 identity 的空資料 replica 開啟同一 address 並通過 runtime contract 核對。
- 交付分階：本階段只建立裁決、工具與本機證據；正式 identity、official ledger 與 private pinning/signaling bring-up 延後至週邊 repo 發布完成後執行，最後才公開 main。

### 2026-07-28 ─ Pinning 公開列舉 API 移除

> 決策檔：[D-20260728-01](../decisions/D-20260728-01-Pinning公開列舉API移除.md)

- `GET /list` 與 `PinningProvider.listPinned()` 沒有玩家、UGC 瀏覽或 DMCA 維運用途，卻會把節點完整 pin inventory 暴露成公開契約；公開 HTTP API、client 介面、adapter、cursor／page-size schema、測試與規格一併移除，不保留相容路由。
- 節點內部仍可透過 `ClusterClient.list()` 彙算 `/stats`、配額與 reconcile；DMCA 案件列舉則保留在獨立的受保護 Admin API。這兩者都不是公開 inventory API 的替代入口。

### 2026-07-28 ─ DMCA Admin 雙重閘與自架 Swagger

> 決策檔：[D-20260728-02](../decisions/D-20260728-02-DMCA-Admin雙重閘與自架Swagger.md)

- 公版 `DMCA_ENABLE` 維持選配，但一旦開啟，`DMCA_ADMIN_TOKEN` 缺席即 fail-fast；不再產生維運者無法取得的隨機 token。Admin 列表改有界摘要、另設單案詳情，禁止輸出 email confirm token，並驗證 action／status 矩陣、reason 與操作者稽核欄位。
- 官方部署使用 `dmca.open4wd.org`，由 Cloudflare Tunnel 隱藏 origin；`/admin/*` 與 `/api/dmca/admin/*` 同時受 Access 身分／MFA 與應用層 Bearer token 保護。公版提供 self-host OpenAPI 與預設關閉的 Swagger UI，官方在同 origin 啟用 `/admin/docs`，不預載、不持久化 token，也不使用外部 validator。
- 瀏覽器操作先通過 Access 再於 Swagger 輸入 `DMCA_ADMIN_TOKEN`；curl／Postman／PowerShell 則同送 `cf-access-token` 與 `Authorization: Bearer ...`。人工裁決路徑不開 Service Auth bypass，Windows bat 只作 PowerShell 包裝。

### 2026-07-28 ─ UGC 下載改為 Bitswap 優先與 Gateway 後援

> 決策檔：[D-20260728-03](../decisions/D-20260728-03-UGC混合下載與流量邊界.md)

- 線上 UGC 讀取順序固定為本機快取 → 玩家／社群 Bitswap（短 timeout）→ 已設定的 HTTP Gateway；每一路都必須通過相同 CID、大小上限與 GLB sanitizer，不把 fallback 變成驗證旁路。
- Bootstrap／DHT 只協助發現 peer，不會自然承擔 UGC payload；只有官方節點直接經 Bitswap 供塊、作 Circuit Relay 轉送，或由官方 Gateway 回應時，該資料才計入官方伺服器流量。初期不對 Bitswap 強制排除官方 peer，先以分來源 metrics 與 relay 上限觀察。

### 2026-07-28 ─ Pinning 可觀測性與官方私有 Metrics

> 決策檔：[D-20260728-04](../decisions/D-20260728-04-Pinning可觀測性與私有Metrics.md)

- 公版提供預設關閉的獨立 Prometheus metrics listener、強型別 port 與 no-op adapter；labels 禁止 PeerId、IP、CID、房碼、案件內容等個資或高基數值。`/stats` 保留為基本健康摘要，不等同 raw metrics。
- 官方 overlay 使用 Prometheus、Grafana、Alertmanager；Grafana 經 `monitoring.open4wd.org` 的 Cloudflare Access／MFA 與 Tunnel，raw `/metrics` 只在內網抓取。告警目前只送私人 Discord；考量經費，不設 Email 通知與獨立外部 uptime heartbeat。
- 指標分開量測 Bitswap、Circuit Relay、HTTP Gateway、DHT／Gossip、storage、cluster、ledger、API 與 DMCA sweep；告警必須同時設定持續時間與最低樣本數，避免低流量環境雜訊。
