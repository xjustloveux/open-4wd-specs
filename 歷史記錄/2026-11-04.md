### 2026-11-04 ─ Tripo 時期 authoring-source Release 棄用（issue 001269）

specs 推版後的 push-safety 複審指出：公開 repo 的第一顆 immutable Release `authoring-source-509d0a0a3e83`（2026-08-18）
仍公開分發 27 顆 Tripo 生成的原件 GLB，而公版已改為程序化從零生成、新 Release `authoring-source-5fe3877815e7`
不含任何 Tripo 原件；版權.md 的規則是未證實再散布權的暫行 bytes 不進公開散布。使用者裁決直接處置舊 Release：
不以 Tripo 條款查證為前提，先由維護者嘗試刪除，GitHub 的 immutable 設定若拒絕則在 Immutable Release 操作說明
明示棄用；該 Release 自此不得作為 authoring 來源、測試素材或參考輸入，lock 亦不得再指向它。同日維護者已成功刪除該
Release 與 tag。

> 決策檔：[D-20261104-01](../decisions/D-20261104-01-Tripo時期authoring-source-Release棄用.md)

### 2026-11-04 ─ 公版 AI 生成圖的權利聲明（issue 001270）

節慶主題、倒數／起跑動畫、空狀態與賽中訊息圖示的母圖由 OpenAI 影像生成產出並隨 Release 公開，provenance 只記
工具、提示詞、尺寸與 SHA-256，版權.md 對公版資產的五項權利證明與 D-20260703-06 的 UGC AI 條款都沒有涵蓋專案自製
的 AI 平面圖。使用者裁決以全域聲明處理：版權.md MIT 段寫明公版 AI 生成平面圖依服務條款輸出歸使用者、專案不另
主張著作權、隨 codebase 以 MIT 散布，五項證明只適用於公版 3D 資產；provenance 去除影像工具暫存匯出檔名、現行素材
改記 PNG 的 SHA-256；美術方向補「提示詞以通用品類語稱呼四驅模型車」。主 repo 賽中訊息 pack 授權字串已於 001274
同口徑改寫。

> 決策檔：[D-20261104-02](../decisions/D-20261104-02-公版AI生成圖的權利聲明.md)

### 2026-11-04 ─ 像素自適應階梯延伸與災難性慢幀計入（issue 001284）

公版程序化交付後 canonical-smoke 首次在 PR 路徑真跑，GitHub runner 的軟體 GL 把比賽場景跑到約 0.5 fps，而像素
自適應把超過 500 ms 的間隔當暫停丟棄、永遠不降階，階梯也只到 45；e2e 取樣 canvas 的元素截圖單次超過 48 秒。
使用者裁決兩端都做：階梯延伸到 30／20 並把超長間隔以 500 ms 計入窗內（背景分頁由 viewport 不餵樣本處理），
e2e 取樣改 CDP 0.1 倍縮圖、poll 放寬到 180 秒。

> 決策檔：[D-20261104-03](../decisions/D-20261104-03-像素自適應階梯延伸與慢幀計入.md)
