# D-20261107-02｜場地閘弧牆穿入改和單顆對照比較

## 背景與驅動力

issue 001306：研究模式場地碰撞閘（`O4_RESEARCH_GATES=1`）的 C 弧牆貼牆格，牆穿入的分段集合最大值超過
2 mm 絕對上限（[D-20261021-01](D-20261021-01-場地碰撞體分段與邊界法線機制.md)）。
[D-20261107-01](D-20261107-01-持續接觸trimesh目標排除部分三角形補掃.md) 的 kernel 下，heavy x=−0.7、
−0.8 的分段集合為 2.26、2.65 mm，判準列由綠轉紅；舊 kernel 的單顆對照已有 2.65 mm 的樣本。單顆不判
穿入，所以舊 kernel 下穿入列沒有紅（這些格另因自我檢查前提列而紅）。

以臨時診斷量 C 弧牆 heavy x=−0.8：單顆與分段各 9 個起點偏移，每次 600 幀。結果如下：

- **外側導輪、弧牆**：穿入只來自外側兩顆導輪。每次執行有牆接觸的幀為 559 幀，逐幀最大牆穿入的
  中位數為 0；超過 0.5 mm 的幀為 26–34 個，峰值平均 0.73–0.84 mm。直牆只量了 A 直線貼牆 10°（分段、
  3 個偏移），最大 15 µm。
- **隨分面轉角增減**：弧牆 63 段時每段轉 2.86°。改成 126 段後，每次執行剩 0–3 幀；改成 252 段後為 0 幀。
  事件多半發生在導輪剛越過分面接縫約一幀行程的地方。
- **CCD、導輪質量、預測距離都不消除**：CCD 子步數設 0 時仍有 25–31 幀；導輪質量放大 4 倍仍有；預測
  距離由 2 mm 加到 5、10 mm 也仍有。其他因素未逐一排除。
- **超過 2 mm 的極值**：18 次執行中出現 4 次，單顆與分段各 2 次，都在 bounded-step 試算拒絕的同一幀或
  其後 5 幀內。
- **單顆與分段分布相近**：兩者都有 2.65 mm 級的樣本。

這道閘只判牆分段的品質。弧牆穿入在不分段時同樣存在，閘量到的是弧牆幾何在 60 Hz 下的接觸特性，不是
分段造成的差異。求解層的機制目前未查明。

## 考慮過的選項

- **只做物理研究，閘維持紅燈**：閘繼續當這個問題的警報，查到原因修好後才轉綠。缺點是研究時間未知，
  期間研究模式一直紅，其他回歸會被這幾格的紅燈掩蓋。
- **C 弧牆的穿入改列觀察**：不設任何上限，分段若讓穿入顯著變差也不會報。不採。
- **協定層改切段**：弧牆依轉角上限切分。這會改變場地切分協定與公版場地產物，又沒有查到機制，等於
  先動協定。不採，留給物理研究（issue 001307）的結論。
- **採納**：閘只就分段品質判斷，C 弧牆的牆穿入改和單顆對照比較；物理機制另立 issue 001307 追查。

## 決定

C 弧牆貼牆格的牆穿入判準，由「分段集合 max ≤ 2 mm」改為「分段集合 max ≤ max(2 mm, 單顆集合 max ×
1.6)」。1.6 倍沿用同一道閘試算拒絕的倍數規則：小樣本集合的極值受抽樣支配。2 mm 下限保留，所以單顆
本身沒有穿入時，分段仍以 2 mm 為上限。

其餘格（A、B、D）維持 2 mm 絕對上限，沿用 D-20261021-01「和單顆比大小量到的是三角走訪順序的雜訊」
的理由。目前只在 C 弧牆量到兩版都有、超過 2 mm 的穿入，所以只有這一類格改用相對比較。

實作上，場景加旗標 `penetrationVersusBaseline`（只有 C 弧牆設定），上限由 `penetrationLimitM` 計算。
判準列同時列出單顆集合 max 與算出的上限。守門：`track-collision-gates.spec.ts` 閘設定 describe 斷言
C 弧牆六格都設旗標；A 直線貼牆、A 牆端、B、D 各格的場景都改由建構函式產生，並斷言全部沒有設旗標；
另斷言上限算式與 1.6 倍常數。

## 後果與影響

- 研究模式 C 弧牆的牆穿入列不再因分面轉角造成的毫米級穿入而轉紅；分段若讓穿入超過單顆的 1.6 倍，
  仍判不過。
- C 弧牆六格的其他判準列不受影響。
- 常駐 CI 輕量模式不跑 C 弧牆，行為不變。
- 弧牆分面接縫的穿入與超過 2 mm 的極值，由 issue 001307 持續追查。查到原因並修正後，應重新評估本
  決定是否回到絕對上限。
- 現況規格：[程式架構/physics-engine.md](../程式架構/physics-engine.md) 品質閘段。
- 與既有決策的關係：amends [D-20261021-01](D-20261021-01-場地碰撞體分段與邊界法線機制.md) 的穿入判準
  （「穿入絕對 ≤ 2 mm」加上 C 弧牆的例外）。

## 定案紀錄

2026-11-07 確認 001306 的根因後，提出三個方向：改閘判準、再研究物理、改切段協定。使用者質疑「找不到
問題就放寬標準」。修正後的建議是閘與物理分開處理：閘只就分段品質判斷，改和單顆比較；物理機制另立
issue 追查，不因閘改動而結案。使用者裁決「依照你的建議」。
