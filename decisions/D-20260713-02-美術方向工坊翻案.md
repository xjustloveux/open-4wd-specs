# D-20260713-02｜美術方向翻案：專業迷你四驅車調校工坊

## 背景與驅動力

第一輪曾核准「克制的機械競速」方向——深色中性表面、Track Bracket、SVG icon 與資訊層級取代 emoji 與系統卡片牆；實際截圖驗收後仍被判定太像管理系統（企業 dashboard 密度），該方案保留為歷史、不再是實作權威（無前 ADR，本檔為翻案形）。

## 考慮過的選項

- 「克制的機械競速」（第一輪核准案）：截圖驗收不過——降為歷史非權威。
- 「專業迷你四驅車調校工坊」（採納）。

## 決定

- 美術方向改為**「專業迷你四驅車調校工坊」**：車輛 ／ 賽道舞台是第一焦點；Stage、Pit Board、Tool Drawer 分層；一個畫面只突出一個主要 CTA；技術欄位收進工具抽屜，避免企業 dashboard 密度與一般賽車比例。
- 為驗證參考圖可高還原，先建獨立 HTML／CSS 樣板；**靜態材質、面板與構圖由 DOM／CSS 負責**，複雜美術才拆成可裁切圖層，**禁止把完整 UI 截圖烘焙成背景**。
- Canvas 2D 原型（合成車、光效、粒子、視差）不承載文字或操作；多 GLB 組裝驗證可行後，正式版改由 Three.js 顯示車輛、Canvas 原型只留作歷史。
- **圖示統一 SVG**（不用字元 ／emoji）；音樂音效 slot 可先為 `null` 並安全 no-op；桌機、平板、手機與方向切換皆保留首要操作、44 px 觸控目標、focus、reduced-motion 與零 document 水平溢位。

## 後果與影響

視覺權威由 [美術資源/美術方向.md](../美術資源/美術方向.md) 承載；車輛呈現路線由 [D-20260714-01](D-20260714-01-Mount組裝車輛呈現.md) 接續定案。早期用於強化工坊識別的 Scale Rail 尺標，其後因數字刻度易被誤解為真實量測而在 [D-20260723-01](D-20260723-01-主題StyleAPI-v1.md) 同輪移除。
