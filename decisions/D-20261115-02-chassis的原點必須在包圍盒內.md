# D-20261115-02｜chassis 的原點必須在包圍盒內

## 背景與驅動力

整車的 root 是 chassis 的原點。比賽的位置判定都以 root 為準：路線位置、路寬、checkpoint、終點、
KillZone、掉落界限與最後合法位置；起跑格與回定位也是把 root 放到目標位置。整車與零件的規則原本只
限制車身的尺寸與掛點相對 chassis 包圍盒的位置，沒有限制 root 相對車身的位置（issue 001409）。root
不在車身上的車，車身與判定用的點不在同一個地方。

## 考慮過的選項

- **要求 chassis 的原點在 chassis 的包圍盒內**（採納），並在首次匯入外部 chassis 時把幾何對齊原點。
- **比賽判定改用質心或車身包圍盒的中心**。牽涉全部位置判定的輸入、起跑格與回定位的擺放、快照與
  觀戰，範圍大。
- **只在匯入時對齊原點**。不經過編輯器匯入的檔案不受限制。

## 決定

- chassis 的原點必須在 chassis 自己的包圍盒內，容差 `CHASSIS_ORIGIN_AABB_TOLERANCE_M`（1 毫米，
  留給幾何量化的誤差）。兩處檢查，不合格都拒收：
  - 零件檢核（編輯器即時層與定稿）：拒收碼 `chassis-origin-outside-aabb`。
  - 整車組裝：以 chassis 的烘焙邊界套用掛點變換後的範圍判定，與整車尺寸同一步。
- 只限制 chassis。其他零件的原點是掛點的基準，不是整車的 root。
- 首次匯入未標記的外部 chassis 時，把幾何整體平移，使包圍盒的底面中心落在原點，再合成掛點。
  掛點模板本來就以底面中心為基準，對齊之後模板的位移就是掛點的座標。重新開啟已定稿的資產不重新對齊。

## 後果與影響

- 原點不在包圍盒內的 chassis 不能定稿，用它組成的車不能通過整車組裝。目前是上線前，沒有需要相容的
  既有內容；三個公版 chassis 的原點都在包圍盒內（離底面 1.4 毫米）。
- 先前匯入、原點偏離幾何的本機草稿會被拒收，需要重新匯入。
- root 在 chassis 的包圍盒內，不代表在整車的幾何中心：其他零件可以讓車身向任何一側延伸，延伸的範圍
  受整車尺寸上限限制。
- 現況規格：[建模參數/零件與共用介面.md](../建模參數/零件與共用介面.md) 第 6.1、6.4 與 7.1 節、
  [程式參數/protocol.md](../程式參數/protocol.md)、[編輯器操作.md](../編輯器操作.md)、
  [UGC機制.md](../UGC機制.md)、[流程/UGC上傳.md](../流程/UGC上傳.md)。

## 定案紀錄

2026-11-15 使用者裁決：準入時要求 root 在車身包圍盒內，並在匯入時對齊原點；不改比賽判定所用的點。
以 chassis 的包圍盒為準、容差 1 毫米是實作時定的。
