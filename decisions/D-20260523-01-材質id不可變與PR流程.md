# D-20260523-01｜材質 id 發布即不可變＋生命週期 PR 流程

## 背景與驅動力

材質 id 被已上鏈資產的 GLB extras 永久引用；若允許 rename，舊資產的材質指派會靜默失效。同時材質清單缺少明文的新增 ／ 變更管道，開源協作下需要可審查的流程。

## 考慮過的選項

（流水帳未記錄替代方案；本決策以補洞、明文化形式成立。）

## 決定

- 鐵則：**材質 id 發布即 immutable、禁直接 rename**；命名錯誤的救濟是新增新 id 並廢止舊 id，不是改名。
- 材質生命週期改由 PR 流程管理（新增 ／ 調參走社群 PR＋ 審查）。
- 附帶清理：全域命名統一 TS 全名（如 `yield` 改 `yield_strength`、去 `_celsius` 後綴）、`is_special_fluid` 改 `is_fluid`、`magnetic_susceptibility` 型別改 `number | null`（載入雙向斷言）、`thermal_limit` pre-bake 取 weakest non-null sub-mesh、carbon 熱階層調整。

## 後果與影響

id 不可變是後續廢止模型（[D-20260612-03](D-20260612-03-材質廢止append-only.md)、[D-20260627-02](D-20260627-02-材質廢止絕版品模型.md)）的前提——廢止只能標記、永不能改寫或刪除。現況見 [材質表.md](../材質表.md)。
