# D-20260817-04｜UI 常數權威收斂至實際消費端

## 背景與驅動力

UI system-constants 保存了一批沒有 production consumer 的版面、動畫、編輯器 guidance、文案 key 與 SEO 路徑。實際行為已分別由 CSS／SCSS、motion safety、頁面直接翻譯 key 與 build generator 擁有，繼續保留 TypeScript 副本只會形成漂移來源；loop route 舒適帶與圈速預估則沒有首發 UX 或算法。

## 考慮過的選項

- 建立 generator 同時產出 SCSS 與 TypeScript 斷點：目前沒有需要數值運算的 runtime consumer，增加工具鏈而無產品收益（未採）。
- 將 reduced motion 改為所有動畫乘 0.5：弱於現行靜態素材與近零時長的無障礙行為（未採）。
- 為 loop guidance 與長版 hero 文案臨時指定頁面：需求與互動尚未設計，會為常數反向製造功能（未採）。
- 保留實際消費端並直接移除副本與未出貨功能（採納）。

## 決定

40em／64em／90em CSS／SCSS 級距及其 script gate 是唯一共用響應式權威；編輯器只在本模組命名用途導向的 compact query。Reduced motion 維持靜態素材、0.01ms 與停用 smooth scrolling。首發不提供 loop route 舒適帶或圈速預估，也不預留常數接縫。品牌頁直接使用 `app.tagline`，長版 tagline 退場。sitemap 與 robots 路徑只由 SEO generator 擁有。

## 後果與影響

runtime 不再攜帶未使用的 px 對照、固定 layout 尺寸、SEO output path 或文案 key。斷點調整必須同時通過 CSS gate；未來若真正設計 loop guidance 或另一版 hero 文案，需以完整 UX 與測試重新提出，而非復活舊常數。現行權威見 [編輯器操作.md](../編輯器操作.md) 與 [ui-frontend.md](../程式架構/ui-frontend.md)。
