# D-20261110-01｜場地閘試算拒絕改比集合平均

## 背景與驅動力

issue 001098：場地碰撞閘（`track-collision-gates.spec.ts`）的試算拒絕判準比較兩個擾動集合的最大值：
分段集合 max ≤ 單顆集合 max × 1.6，單顆集合 max 為 0 時 ≤ 1
（[D-20261021-01](D-20261021-01-場地碰撞體分段與邊界法線機制.md)，
[D-20261028-05](D-20261028-05-bounded-step接受容差放寬至0.2毫米.md) 在 0.2 mm 容差下重量後維持）。
拒絕次數是小整數，研究模式每格只有 9 個擾動樣本，集合最大值容易被單一罕見樣本左右。

為了估計這個規則的誤判率，研究模式中有拒絕的 7 格（C 弧牆 heavy／control 各 x=−0.6、−0.7、−0.8，
以及 A 牆端）兩版各跑 201 個起點擾動，bounded-step 容差 0.2 mm。拒絕次數沿用閘的統計窗：C 弧牆為
600 幀，A 牆端為全部執行都還在場上的前 94 幀。量測結果如下：

| 格                | 單顆 平均／標準差／最大 | 分段 平均／標準差／最大 |
| ----------------- | ----------------------- | ----------------------- |
| C heavy x=−0.6    | 4.53／1.38／8           | 4.33／1.42／8           |
| C heavy x=−0.7    | 3.83／1.24／7           | 3.64／0.90／6           |
| C heavy x=−0.8    | 3.93／1.05／7           | 3.73／0.96／6           |
| C control x=−0.6  | 6.45／1.52／12          | 6.43／1.96／12          |
| C control x=−0.7  | 7.48／1.20／11          | 7.55／1.71／15          |
| C control x=−0.8  | 7.94／1.40／13          | 8.49／1.17／12          |
| A 牆端            | 1.36／1.10／5           | 1.39／1.08／5           |

7 格兩版平均差介於 −0.20 到 +0.55 次。以這些樣本為母體，兩版各重抽 9 個、重複 2 萬次，估計各規則的
單格假紅率；再把分段樣本換成單顆樣本乘 1.5 倍（四捨五入）模擬劣化，估計偵測率：

| 規則                                 | 單格假紅率    | 1.5 倍劣化偵測率：C 弧牆六格／A 牆端 |
| ------------------------------------ | ------------- | ------------------------------------ |
| 現行：max ≤ 單顆 max × 1.6           | 0.00%–10.46%  | 29.2%–39.7%／51.4%                   |
| 平均 ≤ 單顆平均 × 1.25 + 1           | 0.00%–1.17%   | 58.7%–91.8%／27.0%                   |
| 平均 ≤ 單顆平均 × 1.25 + 0.5         | 0.08%–7.66%   | 79.99%–97.66%／53.1%                 |
| 平均 ≤ 單顆平均 + 1.5                | 0.01%–5.88%   | 80.7%–99.97%／19.2%                  |

現行規則的假紅集中在 A 牆端（10.46%）與 C control x=−0.7（6.13%–6.31%，兩次重抽）。

## 考慮過的選項

- **維持現行規則**：假紅率最高約一成，研究閘紅燈時需要另外排除抽樣因素。
- **平均 ≤ 單顆平均 × 1.25 + 1**：四種規則中各格最高假紅率最低（單看 A 牆端，「平均 + 1.5」較低），
  C 弧牆偵測率提高；A 牆端偵測率下降。
- **平均 ≤ 單顆平均 × 1.25 + 0.5**：偵測率較高，A 牆端假紅率 7.66%。
- **平均 ≤ 單顆平均 + 1.5**：C 弧牆偵測率最高，A 牆端偵測率最低，control 格假紅率 2.71%–5.88%。
- **平均規則外加最大值保底（max ≤ 單顆 max × 2 + 2）**：上述模擬中假紅率與偵測率和不加保底差異
  在 1.3 個百分點內，與重抽本身的變動同量級。保底只對單一樣本暴增有作用，模擬沒有涵蓋這種劣化，因此未加入。
- **擴大樣本數**：依本次 201 樣本的耗時換算，兩版各多 9 個樣本時，C 弧牆每格約多 2.6–2.8 分鐘（A 牆端約 11 秒），
  未採用。

## 決定

試算拒絕判準改為「分段集合平均 ≤ 單顆集合平均 × 1.25 + 1」，常駐 CI 與研究模式同一規則。單顆集合
沒有拒絕時，上限即為平均 1 次。騎縫格（B 地面 沿格線、D 坡道 沿格線上坡）的固定上限例外不變。

實作上，`GATE.rejectedMeanRatioMax`＝1.25、`GATE.rejectedMeanSlack`＝1，上限由 `rejectedMeanLimit`
計算，判定由 `rejectedWithinLimit` 執行；判準列同時列出兩版集合的 min–max、平均與算出的上限。守門：
閘設定 describe 斷言兩個常數、上限算式、單顆無拒絕時的上限，以及一組舊規則判紅而新規則不紅的單一
高值樣本。

## 後果與影響

- 單一罕見高值樣本較不易單獨使試算拒絕列轉紅；研究模式估計的單格殘餘假紅率為 0.00%–1.17%。
- 分段若使拒絕次數整體上升，C 弧牆格的偵測力比舊規則好。A 牆端單顆平均約 1.36 次，加上「+ 1」裕度後
  上限約 2.7 次，約為平均的 2 倍；1.5 倍劣化後平均約 2 次，9 個樣本的平均多半仍在上限內，偵測率由 51.4% 降為 27.0%，
  2 倍劣化約 49%。
- 上述假紅率與偵測率都是以 201 樣本重抽估計的，常駐 CI 的 5 樣本集合未另外量測。
- 穿入、法線、抬車與軌跡判準不受影響；
  [D-20261107-02](D-20261107-02-場地閘弧牆穿入改和單顆對照比較.md) 的弧牆穿入 1.6 倍規則不變。
- 現況規格：[程式架構/physics-engine.md](../程式架構/physics-engine.md) 品質閘段。
- 與既有決策的關係：amends [D-20261021-01](D-20261021-01-場地碰撞體分段與邊界法線機制.md) 的拒絕
  判準，以及 [D-20261028-05](D-20261028-05-bounded-step接受容差放寬至0.2毫米.md) 已裁決第 4 點沿用的倍數規則。

答覆是只影響研究閘的判紅規則，不影響遊戲行為。使用者裁決採此規則。
