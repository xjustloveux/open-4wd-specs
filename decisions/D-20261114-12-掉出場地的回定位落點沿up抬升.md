# D-20261114-12｜掉出場地的回定位落點沿 up 抬升

## 背景與驅動力

車掉出場地後回定位到最近的 `RespawnPoint`，沒有 `RespawnPoint` 時回到起點（RP1 中心）。實作直接把車的
root 放在那個點上。編輯器以貼面方式新增 `RespawnPoint`，RP1 也貼在表面上，而車的 root 不在車的最低點，
所以車的下半部一落點就在地面以下，被物理引擎推開（issue 001405）。起跑格沒有這個問題：它沿 RP1 的 up
抬升 `START_GRID_LIFT_M`。

以引擎測試用的車實測（地面在 y 為 0，`RespawnPoint` 貼在地面）：搬移那一步結束時車已被往上推到約
0.038 公尺，速度約每秒 2.6 公尺；把 `RespawnPoint` 放在離地 0.05 公尺時，那一步車只多了一步的重力。

## 考慮過的選項

- **落點沿該點的 up 抬升 `START_GRID_LIFT_M`**（採納）。與起跑格同一個量，不新增常數。
- **要求作者把 `RespawnPoint` 放在離地的位置**。編輯器是貼面新增，作者不知道車的 root 在哪裡；沒有
  `RespawnPoint` 時的起點也無從調整。
- **依每台車的外形算出剛好不穿入的高度**。每台車不同，落點不再只由場地決定；起跑格也沒有這樣做。

## 決定

- 掉出場地的回定位落點，是最近的 `RespawnPoint`（沒有時是 RP1 中心）沿該點的 up 抬升
  `START_GRID_LIFT_M`（0.05 公尺）。up 先正規化。
- 脫離跑道回到最後合法位置的那一種不抬升：那是車自己待過的位置。
- 佔位檢查、被擋住時保存的等待落點、實際搬移，用的都是抬升後的同一個落點
  （[D-20261016-01](D-20261016-01-回定位等待空出的實際落點.md)）。

## 後果與影響

- 這是共識行為變更，影響所有場地掉出場地後的回定位。
- 車在落點從 0.05 公尺落下再開始行駛，與起跑相同。
- `RespawnPoint` 若由作者自己擺在離地的位置，落點會再高 0.05 公尺。
- 抬升量對所有車相同；整車尺寸上限內的車輛外形是否都不會穿入地面，沒有逐一驗證，與起跑格相同。
- 現況規格：[遊戲機制.md](../遊戲機制.md) 第 12.2 與 12.3 節、
  [程式架構/physics-engine.md](../程式架構/physics-engine.md)、
  [程式參數/protocol.md](../程式參數/protocol.md) 的 `START_GRID_LIFT_M`。
