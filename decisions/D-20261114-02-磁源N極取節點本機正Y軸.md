# D-20261114-02｜磁源 N 極取節點本機正 Y 軸

## 背景與驅動力

場地物件與靜態磁源的 N 極原本規定取 sub-mesh 的面積加權平均法向，退化時才改用節點的 +Z 軸。
issue 001374：封閉曲面的面積乘外法向總和恆為零，所以封閉網格的磁源算不出面積加權法向，N 極退回節點 +Z。
場地的實體節點必須有正體積，封閉網格必然落入這個情形；開放的殼靠體素備援取得體積時仍算得出非零的法向，但方向
取決於哪些面沒有封起來，同樣難以預期。glTF 以 Y 為上，一塊沒有旋轉的平放封閉磁鐵板，N 極會是水平的
世界 +Z，朝下的武器磁鐵與它的內積為零，磁源對磁源的作用力也為零。

## 考慮過的選項

- **一律取節點的固定本機軸**（採納）：最簡單也最可預期，改方向就旋轉節點。
- **新增欄位讓作者指定 N 極方向**：最彈性，但多一個要驗證與同步的欄位。
- **只取朝向某半空間的面來算法向**：仍然依賴幾何形狀，結果難以預期。

## 決定

- 場地物件與靜態磁源的 N 極取該 source 材質 mesh 節點**本機 +Y 軸**的世界方向，正規化為單位向量。
- 不再計算面積加權平均法向。
- 武器 magnet 的 N 極不變，仍取 `Axis` empty 的 +Z。

## 後果與影響

- 沒有旋轉的節點，N 極朝世界 +Y（上方）。
- 這是物理共識行為變更：含磁源的場地，N 極方向改為節點 +Y——封閉網格的磁源原本是節點 +Z，
  開放殼的磁源原本是它的面積加權法向。三個公版場地沒有磁源。
- 編輯器尚未顯示磁極方向的箭頭，另行處理。
- 現況規格：[材質表.md](../材質表.md) 第 8.3 節、[算式表.md](../算式表.md) 第 5.1 節、
  [建模參數/場地.md](../建模參數/場地.md) 第 8.6 與 9.4 節、[建模參數/零件與共用介面.md](../建模參數/零件與共用介面.md)。

## 定案紀錄

2026-11-14 審查磁力設定時發現面積加權法向對封閉網格恆退化；使用者裁決取節點的固定本機軸，軸取 +Y。
