# D-20261115-06｜輸送帶改由求解器摩擦帶動

## 背景與驅動力

[D-20260811-03](D-20260811-03-TrackEntity決定性Runtime與預配置碎片池.md) 把輸送帶定為「只作用於實際接觸，
沿 entity local -Z，切向 impulse 受摩擦係數與法向 impulse 上限約束」。實作是在每次步進之後，對接觸物補一個
沿帶向的衝量。

這個做法帶不動貼著帶面的物體（issue 001369）。帶體是不動的 kinematic body，下一次步進時求解器的摩擦把
物體相對於靜止帶面的切向速度往 0 拉，上限同樣是摩擦係數乘法向衝量，補進去的速度大半被抵銷。量測：
帶速 2 m/s、橡膠對橡膠、1 公斤方塊鎖旋轉，貼著帶面靜置起步，180 幀內每幀讀到的速度固定是 0.1962 m/s，
位置由 1.5000 公尺移到 1.2439 公尺，沒有往帶速收斂。只有從高處落下、撞擊帶面的物體才會一次取得帶速。

另外，補的衝量方向固定是 entity local -Z，沒有投影到接觸面的切平面；撞上帶體端面的物體也會被施加沿帶向的
衝量（issue 001370）。

## 考慮過的選項

- **甲：修改 vendored 物理核心，新增 collider 的表面速度，產生接觸時寫入求解器的切向目標速度**（採納）。
  求解器的摩擦約束本來就會讀每個接觸點的切向目標速度，只是核心一律填 0、也沒有設定的介面。
- **乙：不改核心，每幀把帶體往前移動「帶速乘步長」再放回原位**，讓求解器看到帶面速度。帶體的碰撞體在
  一幀內真的往前移再彈回，突出於地面的帶體其前端面會推擠貼著它的物體。不採用。
- **丙：維持現況，規格改成只對撞擊生效**。不採用。

## 決定

採甲。

- **核心**：collider 新增表面速度，以 collider 本機座標表示，預設為 0。產生一組接觸的求解器接觸點時，
  把兩個 collider 的表面速度各自以 collider 的姿態轉到世界座標，取第一個減第二個，去掉沿接觸法線的分量，
  寫成每個接觸點的切向目標速度。兩個 collider 的表面速度都是 0 時維持原本的預設值，結果與改版前逐位元組
  相同。
- **表面速度不進快照**，設定它也不算對 collider 的修改；做法與場地分段群組相同。世界由快照還原之後、
  步進之前，由擁有者重設。
- **表面速度只在產生求解器接觸點時讀取**。接觸存在期間改變它，要到那一組接觸下一次完整更新才生效；
  輸送帶的帶速在建立時設定一次，不受影響。
- **輸送帶**：建立 collider 時把表面速度設為 entity local -Z 乘以 `conveyor_velocity_m_s`（collider 相對
  entity 有旋轉時先轉到 collider 本機座標）。步進之後補衝量的程式移除。
- **推力的上限與方向都由求解器的摩擦決定**：上限是摩擦係數乘法向衝量（摩擦係數取兩邊材質的平均），
  方向落在接觸切平面上。端面的法線就是帶向，表面速度在切平面上沒有分量，撞上端面的物體不被帶動。
- **破壞後**：intact collider 停用，沒有接觸，也就沒有帶動；這一點不變。
- 核心離線鎖定重建，WASM 身分與 runtime 版本字串隨之更新（`RAPIER_VERSION_CURRENT`）。

## 後果與影響

- 貼著帶面靜置起步的物體會加速到帶速：上述量測的設定下，每幀的速度變化不超過「摩擦係數乘重力加速度
  乘步長」，速度不越過帶速，60 幀後速度與帶速的差小於 0.005 m/s。
- 斜坡上的帶體沿帶面方向帶動物體（10 度上坡的測試）。
- 帶輪的車輛：輪胎可以自由轉動，帶面的摩擦主要用來轉動輪胎，輪胎接觸點的速度等於帶速，車身只被滾動
  阻力慢慢帶動。測試的車在 60 幀後車身速度約為帶速的一成。
- 帶體的側面：表面速度整個落在側面的切平面上，貼著側面並壓向它的物體會被沿帶向拖動，上限同樣是摩擦
  係數乘法向衝量；這是表面速度的定義行為，不屬於 issue 001370 的缺陷（那是端面得到沿法線的推力）。
  測試的設定下（重力把方塊壓在側面上、靜置起步），方塊每幀的速度變化不超過摩擦上限，加速到帶速、不越過。
- 沒有輸送帶的場景不受影響：canonical 兩車黃金向量 revision-20 不變。有輸送帶的場景，接觸輸送帶的物體
  軌跡與改版前不同。
- 三個公版場地沒有 `kinematic_conveyor`。
- 現況規格：[零件與場景.md](../零件與場景.md) 第 10.4 節、
  [程式架構/physics-engine.md](../程式架構/physics-engine.md)。
