# D-20260717-01｜車位用途權威化與公開 UGC 收斂（part 與 track）

## 背景與驅動力

7/16 的 UI 計畫沿用早期「公開 vehicle 作品 ／ 加入車庫」構想；重新確認 Loadout 已定案為玩家本機資料後，該構想與現況矛盾。同輪也需要為離線本機測試補權威判準：哪些資產在無網環境下可測、`local:` 測試資產與正式資產的邊界在哪。

## 考慮過的選項

- 沿用 7/16 構想（公開 vehicle 作品、Vehicle CID、Vehicle Publish API、`/vehicles`、`/vehicle/:cid`、「加入車庫」流程）：與 Loadout＝ 玩家本機資料定案衝突（廢）。
- 為離線另建第二個 PeerId profile、複雜離線下架投影、另設草稿或動態報價概念：不建。
- **車位用途權威化 ＋ 公開 UGC 聯集收斂**（採納）。

## 決定

- **車位權威化**：固定一個免費 `local-test` 車位；付費擴充只增加 `formal` 車位。
- **`local:` 資產只能本機測試**：`local:` 零件只能裝入本機測試車位、`local:` 場地只能本機測試，皆不得進 `MatchConfig`、多人房或正式賽事。
- **CID 可測性以本機實際 bytes 為準**：正式車也可離線本機測試，但只能用 builtin 或本機已有 bytes 的鏈上 CID（以 Helia `IDBBlockstore` 實際 bytes 判定，不以 metadata／pin 記錄猜測、不觸網、不用 proxy GLB）；缺 bytes 時保留 loadout 並列出缺項、禁止測試。
- **公開 UGC 聯集收斂為 `part | track`**：不存在可公開瀏覽或上鏈的 vehicle 作品；`VehicleLoadout` 仍可作本機車庫、比賽提交 ／ 證據與 3D showcase，但不是公開作品。
- 單一裝置只維持一個登入身分，清除本機資料即自然登出；離線時 fork 與上鏈鎖定，只能匯出或儲存為本機測試資產。

## 後果與影響

UGC 正常流程收斂為「匯入 GLB 或線上 fork → 編輯 → 上鏈 ／ 匯出」；出口 A 產物（[D-20260705-05](D-20260705-05-送出分岔兩出口.md)）的使用邊界自此權威化，測試資產與正式生態完全隔離。7/16 UI 計畫的 vehicle 公開面（Publish API、車庫流程）正式作廢；與同期連線狀態機離線能力（[D-20260716-01](D-20260716-01-連線狀態機離線能力.md)）屬同一收斂輪。
