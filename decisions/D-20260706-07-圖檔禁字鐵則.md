# D-20260706-07｜圖檔禁字鐵則

## 背景與驅動力

原政策允許圖檔含「通用簡易英文」（READY／GO！等戲劇定格詞以 SVG 寫死不翻）。使用者判定此例外仍存語系問題——英文特權、翻譯權不完整、圖中字 screen reader 不可讀。時點上實作尚零圖檔（GLB／UI 資產 ／logo 皆未產出）＝ 零遷移成本，遂改立鐵則，取代舊政策（無前 ADR）。

## 考慮過的選項

- 維持「通用簡易英文」例外：語系不對稱問題不消失——否決。
- per-locale 分版圖檔後門：明文不設；單一效果連 fallback 四層皆不可行時 ＝ 改設計遷就政策。
- 文字全禁、數字與中立符號放行（採納）。

## 決定

- **出貨圖檔資產禁止內含任何語言文字**；數字 0–9 與跨語系中立符號（`! ? + × % : →` 等）允許。範圍含 GLB（貼圖與幾何字皆含）、UI 資產、default 主題、favicon／PWA icon、og:image（純視覺、文字由 og:title 帶）。
- 分類由 4 改 3：品牌類拆「圖形 mark 圖檔零字 ＋wordmark 以 web font 執行期排版」；戲劇定格詞類廢除、併入 i18n key 可翻類；動態字串照舊。可翻類配**視覺強度 fallback 四層**：CSS、SVG filter on text、Canvas／WebGL 動態文字渲染、圖形層 ＋ 文字層合成。
- **範圍 ＝ 官方出貨資產**；UGC 貼圖不在此政策（不可管、內容問題走檢舉）；第三方含字 badge 不引用（文字連結替代）。
- 主題 review 補「圖檔禁字」檢查項（default 與社群主題同標準，[主題系統.md](../主題系統.md)）；鐵則權威 ＝ [ui-frontend.md](../程式架構/ui-frontend.md)、[美術資源.md](../美術資源.md) 留指標。

## 後果與影響

i18n 全對稱（消滅英文特權）、a11y 改善、跨語系共用單份資產 cache、翻譯權完整交社群；定格詞美術字全面改制為零文字圖形效果層 ＋ 執行期文字帶合成。同日落地複審補 3D 幾何字堵洞、範圍句入權威檔；零件與場地參考圖提示詞本就內建 no-text 負向詞、無需改。
