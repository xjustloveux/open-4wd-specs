# D-20260807-01｜Ko-fi 單軌捐助管道

## 背景與驅動力

D-20260706-01 確立捐助制時，把 GitHub Sponsors 與 Ko-fi 並列為管道，但未先驗證維護者所在地的直接收款資格。GitHub 官方現行直接收款地區清單未列台灣，維護者亦無法完成 Stripe Connect onboarding；Ko-fi 個人帳號則已完成註冊並綁定 PayPal。Canon 因而把尚不可用的管道寫成現況。

## 考慮過的選項

- 維持 GitHub Sponsors／Ko-fi 並列，只加註前者不可用：對外仍把無法落地的管道列為現行營運模式，否決。
- 立即透過 fiscal host 啟用 GitHub Sponsors：官方流程存在，但尚未建立 host 合作，也未確認成本、稅務與治理安排，暫不採納。
- 以已可用的 Ko-fi 作唯一現行管道，GitHub Sponsors 待直接收款或 fiscal host 條件成熟後再評估（採納）。

## 決定

- 現行捐助管道只使用 Ko-fi；規劃中的 `.github/FUNDING.yml` 只設 `ko_fi: xjustloveux`，不設 `github:`。
- GitHub Sponsors 僅在台灣開放收款，或確認 fiscal host 合作可行後重新評估，不以待辦管道冒充現況。
- Ko-fi 帳號是維護者個人且可能供多專案共用；頁面與自動致謝等對外文案採通用措辭，不宣稱為 Open4WD 專屬帳號。
- D-20260706-01 對捐助制、不掛第三方廣告、治理獨立與域名的決定維持有效；本決策只修訂其中的平台選擇。

## 後果與影響

公開 canon 與實際可用管道一致，Sponsor button 也不會顯示尚未成立的 GitHub Sponsors 入口。代價是現階段只有單一收款管道；平台支援地區或 fiscal host 條件變動時，必須重新查證並另作決策，不能直接恢復舊設定。
