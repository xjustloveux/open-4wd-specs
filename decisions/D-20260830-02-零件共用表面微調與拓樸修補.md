# D-20260830-02｜零件共用表面微調與拓樸修補

## 背景與驅動力

既有 raise、lower、smooth、flatten、補洞與橋接核心不依賴場地語意，但整合層只替 track
建立 surface index 與可逆 mesh document，零件公版的小型缺口或表面問題仍須回外部 DCC。

## 考慮過的選項

- 零件只開一般筆刷：無法處理 AI／掃描 mesh 常見的合法邊界洞，能力不足。
- 開筆刷與補洞、橋接，但另外複製一套零件流程：容易讓 attribute、undo 與定稿規則漂移，否決。
- 零件與場地共用同一幾何交易核心，只在控制尺度與 anchor policy 分流（採納）。

## 決定

- 所有可編輯資產在 Wave A 建立 surface query index，並建立 attribute-preserving
  `EditableMeshDocument`。零件 rail 提供 surface 分域。
- 零件開放 raise、lower、smooth、flatten、補洞與橋接；radius／strength 採毫米級預設與步進，
  場地維持公尺級。
- 補洞只有至少一個合法閉合 boundary loop 時出現；橋接只有至少兩個同 primitive 合法 loop
  時出現，且仍須作者明選兩環與正／反預覽。開鏈、分支、non-manifold、winding 不一致、
  重複／退化／相交面或成本超限時整筆拒絕。
- 一次筆劃或拓樸修補維持單一原子 undo transaction。提交後 materialize 當前 overlay 並完整
  重跑 Wave A，volume、surface area、AABB、質心／質量、頂點／三角形與 surface index
  全部驗證；失敗即補償本次 edit。undo／redo 同步切換相符的衍生 facts。
- 零件 mount 不隨局部表面工具移動；相對位置由既有即時驗證重新判定。三出口仍共同
  materialize 文件並走 PhysicsManifest、part canonical finalizer 與 strict validation，失敗不發布。

## 後果與影響

公版零件可在同一 Editor 完成局部造型與水密修補，不增加第二份碰撞真相或零件專用幾何核心。
surface index 的記憶體成本由所有資產承擔，但零件受既有 vertex／triangle 上限約束。
