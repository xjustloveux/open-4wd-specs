# D-20261112-01｜主題音訊採程式合成與預載分層

## 背景與驅動力

issue 001312：音訊系統的 34 個播放槽、主題 fallback 與混音都已實作，但四個主題都沒有音檔。`default` 的 34 個
音訊 key 全是 `null`，三個節慶主題沒有列音訊 key，遊戲全程靜音。節慶主題的交付說明原本寫「音訊沿用預設槽位，
不另創音訊」。

公版素材必須權利來源乾淨。專案沒有可用的授權取樣庫，也不引用既有錄音或樂曲。

`default` 主題的非 `null` 資產原本全部列入 service worker 的 install precache。`default` 七首 BGM 合計 12.35 MiB，
27 個音效合計 0.35 MiB；`default` 主題現有的其他資產約 2.2 MiB。

## 考慮過的選項

- **音檔來源**
  - 外部取樣或素材庫：自然度較高，但每個來源都要查核授權。
  - 純程式合成：波形、旋律與節奏都由版控中的腳本依固定種子產生，權利來源單純，可重新產生；撥弦與鼓組聽得出
    合成感，弓弦、管樂、人聲與原聲鋼琴合成效果差，因此不使用。
- **節慶主題的音訊**
  - 沿用 `default`：主題之間只有視覺差異。
  - 各主題一套：四個主題各有主旋律樂器、調性、速度與動機。
- **同一槽位跨主題的差異**：第一版四個主題的每首 BGM 共用同一份段落編排。量測音量起伏的跨主題相關係數，
  首頁曲為 0.64–0.75、比賽曲為 0.58–0.85；三個路面循環音的 1/3 八度頻譜平均差只有 1.0–6.5 dB。
  - 維持共用編排。
  - 首頁曲與比賽曲各主題另行編排，節慶主題不提供路面循環音。
- **音檔進版控的方式**
  - 降低位元率以縮小 repo：四個主題合計約 52 MiB，降低位元率會犧牲音質。
  - 維持現有位元率，之後只替換內容有變的檔案。
- **`default` 音訊的預載**
  - 全部列入 install precache：首次安裝要多下載約 12.7 MiB。
  - 全部不列入：離線時連操作回饋音都沒有。
  - 音效列入、BGM 不列入。

## 決定

1. 四個主題的 BGM 與音效全部以程式合成產生。產生器、風格設定與逐檔清單放在
   [美術資源/主題音訊](../美術資源/主題音訊/README.md)，出貨的 `.ogg` 放在主 repo 各主題的資產資料夾。
2. 三個節慶主題各自提供 7 首 BGM 與 20 個音效。四個保留槽依既有規則恆取 `default`；三個路面循環音
   （`sfx-surface-hard`、`sfx-surface-loose`、`sfx-surface-slippery`）節慶主題不提供，沿用 `default`。
3. 首頁曲與比賽曲在三個節慶主題各有自己的段落編排；萬聖節比賽曲用 6/8 拍。其餘五首四個主題共用段落範本。
4. 音檔維持現有位元率（BGM 96 kbps、音效 64 kbps）進版控；之後調整時只替換內容有變的檔案。
5. `default` 主題的音效列入 install precache，`bgm-*` 不列入。

## 後果與影響

- 重新編排後，同法量測的跨主題音量起伏相關係數，首頁曲為 −0.41–0.29，比賽曲為 −0.15–0.24。這個數字只反映
  「哪裡變滿、哪裡抽薄」是否同步，不代表旋律或音色的相似程度。
- 主 repo 增加約 52 MiB 的二進位檔。各主題含音訊後約 15–17 MiB，低於 `THEME_SIZE_MAX_MB`（20）。
- install precache 增加 0.35 MiB（27 個音效）。`default` 的 BGM 改為播放時才取檔；離線且尚未取得過的 BGM 會靜音。
  BGM 目前以媒體元素播放，取檔後是否會進 service worker 快取、循環接點是否無縫，都還沒有在瀏覽器驗證
  （issue 001315）。
- 音檔的音樂性只經過使用者試聽部分曲目，其餘以程式量測響度、峰值、頻段占比與循環接點。
- 節慶主題交付說明中「音訊沿用預設槽位，不另創音訊」一句改為各主題自備音訊；保留槽不可被主題覆寫的規則不變。
- 現況規格：[程式架構/audio-system.md](../程式架構/audio-system.md)、
  [程式架構/pwa-offline.md](../程式架構/pwa-offline.md)、[程式架構/themes.md](../程式架構/themes.md)。

## 定案紀錄

2026-11-10 使用者要求為四個主題產生 BGM 與音效，並確認風格設定、配器與 BGM 長度。2026-11-12 使用者裁決把四個主題的
音訊換進專案，音檔進版控的方式與預載分層依建議採用；看過跨主題差異的量測後，裁決首頁曲與比賽曲各主題另行編排、
萬聖節比賽曲改回帶圓舞曲感的拍子、節慶主題的路面循環音沿用 `default`。
