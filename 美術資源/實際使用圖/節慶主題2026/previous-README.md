# 原始設計參考

`previous-prompts.json` 保存核准的首頁與 UI 設計提示詞。萬聖節以美式復古雕刻與票券構成操作介面；聖誕節以彩鉛紙紋、紅綠紙卡、主面板冬青與次要星形角飾建立層次。

核准 PNG 母圖位於 `release-input/ui/themes/halloween/` 與 `christmas/`。本目錄 `sources/` 保存可編輯 SVG 和 CSS；正式交付範圍及重建入口以 [節慶主題 2026](README.md) 為準。

視覺工作區的 `authoring-backup-20261024/` 是人工授權保留的完整工作備份，包含舊測試 build 與截圖，不是 Release payload，也不是目前資產完整性的驗收依據。
