# default-inspired 賽中訊息圖示提示詞

> 本檔保存已用於 96 張原始圖的生成提示詞。圖庫與網站 `ThemeService` 無關，即使視覺靈感來自 default，也不隨網站主題切換。

## 共用提示詞

建立一張 256×256、透明背景、置中且四周保留 12% 安全邊界的遊戲 HUD 無字圖示。風格為高能量機械競速貼紙：俐落粗輪廓、深石墨色外框、青藍與速度黃主色、少量白色高光、清楚的前後景與動態線；縮到 64×64 仍能辨識。只畫下表指定構圖，不要加入任何文字、字母、數字、標點、對話框文字、商標、水印、UI 外框、網站主題元件、真實品牌、血腥或寫實暴力。輸出正方形 RGBA 原始圖；原圖驗收後由 main repo 腳本縮放並轉為 WebP。

## 產物位置與驗證

- 96 張原始圖位於 `release-input/ui/race-messages/default/`，一個 `messageKey` 一張 PNG。
- main repo 產物位於 `public/assets/race-message-packs/default-inspired/`，含 96 張 WebP 與 manifest。
- 完整 gate 逐張驗證可解碼、256×256、alpha、64 KiB 上限、byte size 與 SHA-256；另須目視確認無字、語意辨識與縮小後可讀性。
