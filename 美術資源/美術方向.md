# 美術方向（GLB Art Direction）

> **本檔角色**：公版 GLB 的美術方向、比例、零件辨識標準與 IP 邊界（**參考件、非 spec**）。
> 功能規格以 [建模參數.md](../建模參數.md)／ [程式架構/builtin-assets.md](../程式架構/builtin-assets.md) 為準；UI 美術原則見 [設計系統.md §1](設計系統.md)與 [主題外觀與 RWD.md §6](主題外觀與%20RWD.md)。

本文件定義 Open4WD 的 3D 資產方向。現有程序化 GLB 只能作為 layout blockout 與技術驗證，不可直接視為公開上線美術品質。

## 參考原則

可以參考現有動畫、漫畫、實體玩具與遊戲的品類語言，但不得複製任何具體 IP：

- 不複製既有車名、品牌標誌、貼紙、角色圖案、代表性輪廓或獨特零件造型。
- 只抽取共通結構語言：低矮楔形車殼、外露輪胎、前後保險桿、導輪、底盤孔位、電池/馬達艙、窄長賽道與護欄。
- 比例與功能可參考公開規格，但造型、塗裝、零件細節必須原創。

## 基準比例

參考 Mini 4WD 類型常見比例，Open4WD 資產使用下列建模基準：

- 車長約為車寬的 1.55 到 1.7 倍。
- 輪距接近車寬的 60% 到 70%。
- 軸距接近車長的 50% 到 55%。
- 車殼高度低於車長的 22%，避免看起來像卡車或積木。
- 導輪與防撞翼必須明顯外露，讓玩家一眼辨識這是軌道競速車。

## 車輛輪廓

每台車至少要有以下元素：

- 低重心底盤：黑色或深灰主體，保留孔位、螺絲座與安裝槽。
- 楔形車殼：前低後高或中央駕艙隆起，避免完整方盒。
- 前後保險桿：比車殼寬，能掛導輪。
- 四輪與輪拱：輪胎必須從車殼外側清楚露出。
- 4 到 6 顆導輪：前後至少各 2 顆，必要時加側導輪。
- 馬達/電池暗示：可用艙蓋、散熱孔、端子或透明罩呈現。

## 零件分類視覺

正式零件類型 = 8 類（`chassis / body / tire / motor / battery / roller / chip / weapon`，見 [建模參數.md](../建模參數.md)）。`shaft`／`gear` 只可作為 chassis 內部視覺元素，`aux` 造型必須歸入 body 或 weapon；三者都不是上傳零件類型。

- `chassis`：應是可裝配平台，有孔位、軸座、電池槽、馬達槽與前後 stay；傳動軸與齒輪作為內部視覺元素呈現（金屬細軸、有齒形的齒輪，不可只是圓柱）。
- `body`：應像可拆車殼，不應像單純長方體。
- `tire`：有輪胎、輪框、胎紋，材質與輪框要分色。
- `motor`：圓角金屬罐或盒型馬達，含輸出軸與端子。
- `battery`：雙電池或電池包，含正負極標記。
- `roller`：導輪要有外圈、軸承、中心孔。
- `chip`：PCB 造型，含焊盤、晶片、走線。
- `weapon`：必須和車體比例相容，不能變成巨大刀片或不合規玩具。

## 場地輪廓

場地 GLB 必須像可以實際比賽的軌道：

- 跑道有外牆、內牆、路面、檢查點與起終點。
- 路寬能容納 4 到 8 台車，不可只是裝飾環。
- 危險區需是場地元素，例如泥地段、跳台、風區、磁場板、水窪或碎石區。
- 手機畫面仍要能辨識賽道走向與車輛位置。

## 建模流程建議

正式資產不應只靠目前的 JS 程序化生成器完成。建議流程：

1. 先建立 3 台原創車型：speed、heavy、control（對應公版 archetype，見 [程式架構/builtin-assets.md §5](../程式架構/builtin-assets.md)）。
2. 每台車拆成可替換零件，確保零件 GLB 與整車 GLB 使用同一套比例。
3. 用 Blender 或等效 DCC 工具建模，輸出 GLB 2.0。
4. 每個 GLB 需通過 main repository `pnpm check:assets`（內含 GLB inspect、manifest、幾何、貼圖與 metadata gate）。
5. 每個模型在桌機與手機 mockup 中截圖審核。

## 現有檔案狀態

`release-input/parts/` 與 `release-input/tracks/` 保存本次待發布的 27 顆 builtin authoring 原始
GLB 及其審查圖，並由 `authoring-source-manifest.json` 鎖定 GLB logical path／hash；它們是本機
Release 投遞來源，不是長期 bytes 權威或 runtime 路徑。每次衍生正式資產仍須通過 manifest 與
release gate，美術方向則以本文件作人工審核準則。
